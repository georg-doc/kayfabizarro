# KFB Legacy Web Pet · Chrome Extension

Source-only v0.

Build locally:

```bash
npm install --no-save esbuild@0.25.9 three@0.160.0
node extensions/kfb-legacy-web-pet/build.mjs
```

Then Chrome → Extensions → Developer mode → Load unpacked → select:

`extensions/kfb-legacy-web-pet/dist/`

For review, prefer the GitHub Actions ZIP generated by this slice; it contains the same built `dist/` files.

The extension executes only bundled local JavaScript. KayKit GLTF/GLB **assets** are fetched from exact pinned `raw.githubusercontent.com` revisions.

Controls:
- left-click pet: random Legacy animation + SFX + VFX;
- right-click pet or camp: character picker;
- click camp: return home.

LLM chat is intentionally deferred.
