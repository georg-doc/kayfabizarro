## Outcome
Created one style contract and one Claude Design execution brief for the KFB Joyride direction.

Core decision:
- Characters / hero props = **clay-first**.
- World = **mixed handmade materials**, not pure clay.
- Geometry may stay deliberately simple/procedural if its material identity makes the construction intentional.
- World reactivity is tiered; not everything becomes a rigid body.
- Race is not required for the world design.
- Existing KFB roads/tracks are kinetic world attractions, not discarded assets.

## Donors retained
- K2 clay-material v10 / clay profiles;
- T4 track / transition / clay VFX grammar;
- World Core R0A as visual/recipe donor only;
- KFB Stunt-Car Free Roam S04 as road/play-network donor;
- Road Family Atlas as modular road vocabulary;
- ClayBound as material/form reference only.

## Explicit corrections
- Do not copy R0A's performance cost.
- Do not make every object clay.
- Do not make every object physical.
- Do not use TinySkies code in the clean KFB runtime.
- Do not let Claude Design own locomotion, vehicle physics, camera, input or state routing.
