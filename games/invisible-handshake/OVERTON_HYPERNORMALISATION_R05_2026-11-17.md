## Design thesis
**The truth of the game-state is public and mechanically unambiguous; the public explanation may be disputed, manufactured, amplified, censored or inverted.** Players contest an accepted discourse, not an epistemic "truth meter". Source-backed history, authors' theories, disputed claims and game-fiction are different categories even if the game intentionally makes its protagonists confuse them.

The **Overton Window** in its original policy sense denotes the contiguous set of positions deemed politically acceptable at a given time; its position and size can change. The concept is associated with Joseph Overton and the Mackinac Center. It is **not** by definition proof of censorship, mass mind control, or that a claim is true/false. See https://www.mackinac.org/7504 and https://www.mackinac.org/blog/2025/what-is-the-overton-window .

**Hypernormalisation:** use Yurchak's analysis of late-socialist normalized public performance and Curtis's later documentary as different works and interpretations. Do not claim their contents prove a total contemporary mind-control mechanism. Fictional use: players knowingly inhabit a public narrative that differs from the mechanically visible network state. KFB already features kayfabe and hypernormalised performance in its public Field Report: https://kayfabizarro.pages.dev/#kfb .

## A — Minimal movable shared window over the four-card Market (test first)
**Components:** Existing four public MARKET Institution slots and **one two-slot paper frame/clip**. No extra cards; clip is game aid. Window starting position covers slots **2–3**. It has exactly three positions: [1–2], [2–3], [3–4]. The **left-right order is physical card order, not left/right ideology or an objective truth scale.**

**RECRUIT (candidate adjustment):** Inside the current window = costs 0 FAVOR; outside = costs 1 FAVOR. The existing 1 FAVOR income at start of each turn and cap 3 remain. A card outside is not forbidden and does not receive an extra attack penalty. It may still be acquired. Other R0 actions/POACH/VETO/NEED score unchanged.

**P04 SHIFT THE WINDOW (candidate Plot):** "Move the shared Window one space left or right, then RECRUIT one Market Institution inside it for 0 FAVOR." This is **one existing PLOT action**, not a free additional turn. At an end stop only the valid direction is legal; no off-board wrap. It **replaces one planned duplicate** of an existing PLOT in the 12-slot Plot budget (e.g. P01×4, P02×4, P03×3, P04×1), it does not add a 57th card. The new plot can still refill its holder's Plot hand as R0 says.

**Semantics:** Players can promote an Institution into public acceptability or marginalize its competitor. Their action can be voiced as press campaign, think-tank paper, false scandal, fact-check dispute, viral celebrity intervention or platform reclassification, but the mechanical effect is always the same relocation and one recruitment.

**Effects:** A card inside the window is amplified by lower acquisition cost; one outside is still recruitable for 1 FAVOR (soft exclusion). This creates an opportunity-cost tradeoff: spend FAVOR to access unfavored institutions now, or keep it for a POACH or VETO. It does **not** presume either side is truthful, just or the only voice in a real society.

**Problems with A (important):** This four-card MARKET is shuffled and replenished, so juxtaposition is **not a substantive policy continuum**. A is at best a *public-distribution/attention aperture* inspired by Overton. If it is experienced as arbitrary shopping tax, FAIL it rather than invent "legitimacy" semantics. A true policy-specific Overton window may need a printed five-position ISSUE strip, which is **B** below and stays exploratory.

## B — Issue spectrum (defer unless A fails thematically)
One **ISSUE** defines five plainly opposed policy framings, e.g. "Classified AI research: complete secrecy / sealed oversight / restricted public review / open research / radical open access." A movable two/three-position overlay covers currently legitimate positions. **Do not print a new Issue deck**. A is still first test because B requires designers to specify what a card actually advocates and avoid incoherent universal left/right coding across unrelated issues. Test B with one hand-written strip only if A lacks meaningful story.

## Related operations through existing R0 verbs
| Fictional operation / stage | Table verb | One concrete effect |
|---|---|---|
| **Problem** / engineered controversy | Event or SUSPEND | Remove one supply temporarily, creating visible unmet NEED |
| **Reaction** / outrage, fact-check, counter-narrative | existing VETO or PLOT | Defend an Institution or expose weakness; one response only |
| **Solution** / the "inevitable" rescue | RECRUIT / POACH | Install a new dependency and gain control of the necessary supplier |
| **PsyOps / false flag** | Existing P01-like SUSPEND theme | Reframe the responsible actor in fiction; no extra truth points |
| **"MKULTRA 4.0"** | Fictional P02-style POACH/VETO theme | Change which network owns an exposed intermediary; no claim of documented contemporary Monarch successor |
| **Amplify / suppress / distract / reframe** | Window shift or existing PLOT effects | Alter public acquisition cost or suspensions, not players' access to real information |

**Attribution:** "Problem → Reaction → Solution" is not an exact formula from Hegel. A useful **game-fiction dramaturgy**; Hegel's dialectic more carefully involves determinate contradiction and `Aufhebung`, both negation and preservation (https://plato.stanford.edu/entries/hegel-dialectics/). Keep "manufactured crisis" a tactic used by fictional factions rather than equating dialectics with a documented universal control technique.

## Kayfabe and Bizarro / improv without punishing strategy players
The actual KFB website uses **Name It → Claim It → Power It** for the freer Freestyle mode and a table "BLÖDSINN!" challenge: https://kayfabizarro.pages.dev/#kfb . For this *separate* rules-driven card game, Georg's experimental **SHOW IT → SPIN IT → SELL IT** could be a **voluntary 10-second performance**, where a non-improv player simply reads a printed public-claim line. The card resolves by text irrespective of acting ability or jury vote. No subjective bonus points and no mandatory storyteller veto.

**Kayfabe:** Public promise versus material interest. **Bizarro:** Critics of control reproduce mechanisms of control. **HyperNormalisation:** Everyone knows an official story is performed, yet institutions react to it as though it were the only available reality. **Overton:** Players compete over what *can be advocated without extra expense*.

## Source inspirations to compare, not copy
- **JUNTA!** Publisher rules, https://alderac.com/wp-content/uploads/2015/04/Junta_rulebook-1.pdf : political game assigns offices, President proposes budget, secret agendas/bribes and possible coup; transfer **conflicting dependencies, limited veto and faction switching**. Do NOT import its nine-round phase stack, location assassination and separate coup tactical board.
- **Machiavelli, The Prince XVIII** https://www.gutenberg.org/files/57037/57037-h/57037-h.htm : appearance vs actual incentives; the political use of perceived virtue. Transform into public/private/Bizarro card fields, not a new morality meter.
- **Sun Tzu, The Art of War** https://classics.mit.edu/Tzu/artwar.html : deception, alliances, information asymmetry, avoid direct conflict, strike network weak points. Translate as choosing exposed nodes and denial of resources, not physical combat or detailed covert operations.
- **Hegel** as above: contradiction/negation/preservation as philosophical motif; NOT formal authorship of "Problem Reaction Solution".
