## 1 · One Site, five work surfaces
- **Play**: variant selector; 1–6 humans and active bots, six visible card fields; guided legal moves; real art, inspect card text, same R24 tower scene. Human chooses action; core validates; scene animates committed outcome.
- **Learn / Demo**: per-variant guided 4–6 beats (goal, turn, claim, loss/next player, victory); then seeded complete bot demo or takeover at verified checkpoint. Play/pause/step/seek, speed, captions and audio on/off; tutorial isolated from save until explicit continue. R09 learn-state donor, not a new LLM at runtime.
- **Rules / Configure**: constrained settings (movement, gate, claim, hand, victory, turns, bot mix), duplicate versioned preset, show diff; import/export JSON, validate and reject unknown rules rather than silently accept. Never execute arbitrary natural-language or pasted JS as rules. Chat produces validated variant JSON plus text/replay fixture; standard action IDs. New mechanics require owner adding one tested action handler, not pretending every game is configurable.
- **Simulate / Compare**: headless same engine (no renderer, audio or paid calls), deterministic seeded PRNG, batch in worker/chunks/cancel. Matched deck/start seeds and rotate seats; compare multiple policies (random legal, greedy claim, card-aware if tags actually exist) at same counts; state invariants, wins by seat/role, match length in turns, attempts/claim, gate waits, unique cards, choice count, stock/discard, tie/cap. Time to understand/fun require humans, not inferred from bot results. Report seed, rules hash, policy versions, sample size, draw/timeout denominator; don't equate same seed with identical random trajectory for differing actions.
- **Print / Tabletop**: one-page English rules + seven-card layout, six faction markers, optional rotating gate marker template, component list, worked turn and match end from same variant. 3 state D6 are not movement randomizers; separate physical D20 for Quick Claim. Plain offline print rules must not depend on app or hidden tags. Later optional QR/companion voice; local hotseat first, remote online separate authority project only after rules stable.

## 2 · Three testable rule presets, not three engines
**A — Quick Claim (R26 control).** No moving pawns. Six outer real cards + central Focus. SET 3 distinct dice at1; then move current role die to different occupied die-free outer slot, +1; optional hand-card stake D20<=sum, success trophy/refresh/reset as R25/R26, failure discards stake, TILT no trophy. 3 trophies candidate. 1H+1 active bot and 2H control. Cards matter narratively; category bonus B from R26 remains a separate switch, OFF.
**B — Tower Circuit (new proposed KISS contrast).** One own existing KayKit pawn per active player, six outer cards form ring, six fixed spokes lead to central Focus; start at own seat. Separate actor seat and pawn sector, stable card identity, no card-slot movement. One action: move clockwise one OR two sectors (choice, no roll); read/reveal landed card and mark its sector visited this case (distinct sectors excluding start), OR claim if at an open spoke and visited >=2 distinct sectors this case. Two opposite open spokes, rotate +1 after each full active-player circuit; physical ring/disc or two markers reproduces exact state. Staying at a closed gate cannot stall indefinitely; move 1/2 prevents simple constant phase lock, verify fairness. Claim deterministic, no W20/state-dice active in B, so compare the spatial loop separately. Success: take actual Focus trophy, reveal new center from stock; keep pawn positions, clear all visit marks, rotate gate +1, start next case with next starter, reset full-circuit counter. If stock empty end (most trophies, tie shared); 3 trophies wins. No blocking/shoving/stack limits for pawns initially (visual offsets, cards still have one stable slot). 6 faction cards plus shared 50 narrative stock optional; no mandatory private hands in B. Finite simulation turn cap = diagnostic censored match, not human win. Offline: printed cards and pawns, two opposite arrow tokens, six visited counters or simple note, no computer. Main caveat B: card subject may still be fungible mechanically; test a separately labeled B2 where a hand-card category match to landed card allows one bonus step, only if visible printed source tag exists, cost/replenishment explicitly tested; not in B or approved.
**C — Borromean Gate (later controlled hybrid).** Reuse B path/visit/gate state and A role dice pressure. First test A/B in isolation. Candidate C entry allows one normal B movement and one legal role MOVE+TURN per turn (or initial SET); claim replaces movement, only eligible at open spoke with all dice set, D20<=sum, one named stake. TILT before a legal increment collapses center as A, clears visits/reset pressure; no hidden physics. Exact turn order and stake/refill/reset contract must be pinned before implementation. No claim that C is balanced or ready. Calvinball variants only between cases later: publicly announce one changed rule, lifetime and end event, no hidden midturn override.

## Addendum R27.1 · Mobile Borromean obstacles and stepped ring (Georg, 26 November 2026)

### D — Obstacle Circuit (new challenger; working description only)
- Keep the existing B ring, six card anchors, six spokes, rotating opposite entry gates, pawns, visit requirement, trophies and case resets. Three shared state dice occupy three different outer cards; no die on center or an intermediate step. Use R24 die pads beside cards so face, artwork and legal movement remain readable. Pawns and role dice are different state objects. Placement changes connectivity, not physical colliders. Cards remain the destinations, not decorative numbered tiles.
- First comparison D1: B's choice of 1 or 2 clockwise steps; add the R23 role sequence and one legal MOVE+TURN at end of a normal turn (initial SET to 1 on distinct cards in first three turns, or prepared 1/1/1 demo explicitly labeled). The acting player chooses the target from currently die-free cards; do not displace a pawn already on that card. An existing pawn can leave a newly blocked card without a test. No stacked dice, no forced teleport. B-style deterministic claim uses a separate action, open spoke and two distinct visited cards; claim from a blocked card requires it to have been successfully entered that visit or otherwise cleared under the selected preset (record clearance per pawn/card/die revision; no hidden arbitrary access). Capture resets pressure to 1, visits and clears as specified in B; TILT at attempted increment above 6 resets current case without trophy, new Focus if supply allows. Do not silently wrap 6→1 as a free action. D1 may initially isolate the obstacle with deterministic scripted die movement for tutorial; full game must expose the legal choice, and face/slot/turn decisions must be logged.
- **D1a — hard bypass:** a die-bearing card cannot be entered or counted as visited. A jump can cross it as a single explicit action to the next die-free card (maximum 3 intervening blocked cards, no extra visit for skipped cards, no bonus claim). Test against a separate bypass-cost challenger: each crossed edge counts against movement budget; if insufficient, offer explicit wait/jump rather than soft-lock. An occupied pawn may always leave. Never count a skipped card as discovered. These are mutually exclusive traversal policies, not both active.
- **D1b — threshold test:** when the intended move first reaches a blocked card, roll one distinct neutral D6 once (not one of the three pressure dice). Provisional first comparator per Georg: roll < displayed face = pass; roll = face = exact pass with its own event (separate optional challenger: +1 step on that turn, cannot trigger repeated bonuses); roll > face = stop on previous legal node, movement ends. Successful crossing continues with remaining steps; if another barrier is encountered, stop before it this turn (first candidate only one test/turn, no chained rolls). Roll committed only after chosen movement; no free previews/retries. Exact event distinct even when no mechanical bonus enabled. A skipped/failed card is not visited. Alternate direction if high face is meant to be stronger obstruction: roll > face passes; = exact; < fails. The user's under-roll idea makes rising tension make barriers *easier*, which can be interesting as destabilization/unlocking, but opposite to increasing resistance. Keep both interpretations as explicit variants, not a hidden inversion. For threshold t=1..6, strict under probability (t−1)/6, exact 1/6, over (6−t)/6. With equality also passing: t/6 or (7−t)/6 respectively. At t=1 or 6 one strict outcome is impossible; check whether that is fun, and guarantee an exit route/explicit skip or bounded wait rather than indefinite blockage. No D20 in the initial D1 experiments; it belongs to A/C claim test. D1a and D1b compare to B, not automatically combined.

### D2 — Intermediate walking fields (separate geometry/movement factor)
- Configurable 0, 1, 2 or 3 intermediate fields per adjacent card pair; equal spacing for first comparison. Ring node count = 6×(1+n), respectively 6, 12, 18, 24. Six cards retain their permanent sector IDs; intermediates have no card ID or printed lore. Spokes and rotating gate access remain only at actual card anchors. Keep R24 layout and scene owners. Use existing physical Board Game Bits / path markers, with source isolation before integration; no general hex terrain grid, no new scene.
- First compare B/ D1 with zero intermediate fields, then test 1–3 as a separate factor. A distinct movement D6 gives 1–6 edge steps clockwise; intermediate nodes may be ending positions; only landing on a card counts as a visit, not merely crossing it. An obstacle is encountered on attempted entry, not only final destination; never silently jump it due to a large roll. Extra fourth D6 can be reused for a separate explicitly rolled challenge (movement roll and challenge roll are distinct events), or use choice movement + only one obstacle roll as in D1b. Do not use the persistent Borromean dice as randomizers. If random movement makes aiming at a gate too dependent on luck, test capped voluntary 1..roll choice separately, not as default. Spoke entry is a separate claim action, no implicit extra movement. Track how extra fields alter match length/visit frequency/reading cadence; longer track is not necessarily more fun.
- New UI/diegetic affordances: show occupied card, die value and role, open vs blocked path, pawn stop location and exact-roll animation; source R24 `DiePads`, `HexFactionSlots`, `die.moveTurn`, `spell.cast`; add pawn/edge/gate events only if missing. Existing R24 has no verified movement/blocking engine. Tutorial English (later DE) explains only active variant; physical rules sheet uses same markers and one neutral D6. No mandatory new cards or purchased models.
