# Georg design correction — VISUAL / EXPERIMENTAL FILM is a first-class HyperNorm plane
Date: 2026-10-24
Status: **USER DIRECTIVE / BINDING CREATIVE PRIORITY IN THIS RESEARCH**, not implementation authorization or tested visual result.
Owner: existing KFB ToolBox / Billboard Media Residency, PR #354. Research packet: Draft PR #450. One research branch; no new engine owner.

## The correction (Georg)
The first R1 atlas erroneously described LHOHQ's "flashing images and provocative montages" as a **surface** and elevated semantic/research branching above the actual audiovisual work. Georg explicitly rejects that hierarchy:

> LHOHQs häufig beschriebene blinkende Bilder und provokativen Montagen gehören zur Oberfläche. -> genau das ist eine super wichtige KFB HyperNorm engine ebene für:
> - Experimentalfilm, Collage, Code, Remix und generative KI

**Interpretation:** HyperNorm is an **audiovisual experimental-film, collage, code-art, remix, and generative-AI instrument in its own right**. It must not be reduced to a quote-read-along, media literacy exhibit, evidence graph with illustration, or pretty bibliography. The *material*, cutting, typography, rhythm, distortion, visual surprise, optical sensation, provocation and performative intensity have independent artistic value.

**Explicit precedence:** this user direction overrides any earlier R1 text implying that audiovisual shock, flashing, hard cutting, provocative collisions, noise, collage or hypnotic effects are "mere surface", or that every visual cut needs a semantic link, a documentary source claim, or a narrative payoff. The old historical R1 analysis stays for traceability; it is not the current design priority.

## Three equal engine planes (not a ranked chain)
### A. AUDIOVISUAL EXPERIMENTAL ART · independent core
- **Editing time:** frame holds, single-/few-frame accents, high-frequency alternation, staccato hard cuts, jump cuts, freeze/smear, match cut, nested loops, visual polyrhythm.
- **Collage materials:** found/public-domain media where rights cleared, paintings/posters/film strips, scans, photography, KFB comics/cards, photomontage, cut-outs, handwritten marks, diagrams, abstract synthetic fragments. Avoid hotlink/scraping and keep user-supplied protected material private.
- **Code art:** image feedback, recursive frame-in-frame, optical flow-inspired distortion, scanline/slitscan, kaleidoscope, chromatic separation, halftone/screen print, threshold, posterization, compositing masks, interference/moiré, fractals, analog-style frame degradation where art-directed (not a blanket 'glitch filter').
- **Typographic cinema:** typography as material/movement, collisions of scale and weight, vertical text, type masks, rhythm-synchronous legibility shifts, repeated mantras vs discontinuous type, kinetic glyph fields.
- **Optical experiences:** tunneling, spinning/vortex, unstable figure/ground, afterimage, improbable perspective, forced symmetry, recursion, mirror/portal imagery; use existing H13 hypno/fractal family first.
- **Music-reactive composition:** drive cuts, camera, typography, modulation, texture and intensity with **existing H13 songform and current KFB Audio handoff**, not a new media timer/audio analyzer/mixer owner. Use measured music/signal, not invented beat metrics.
- **Generative AI:** optional curated generation of original imagery, recombination/compositing material, motion studies and designed variation. It is a *creative production source*, not an excuse to replace montage craft with unreviewed random output. Provenance and rights remain tracked.
- **Remix as method:** concrete transformations of source with materially different composition, duration, repetition, pacing and meaning. No direct copying of LHOHQ files or artwork without per-asset permission.
- **Provocation:** deliberate hard collisions and perceptual tension may be valid artistic outcomes. Do not paternalistically declaw them into neutral infographic storytelling.

**Valid standalone outputs:** an art-directed 10-second seamless eye-candy loop, a 30–90-second visual music film, an abstract material/optical study, or an indefinite generative installation. **None require quotes, FrizzleQuestion, plot, thesis or archival evidence.** For quote-read-along mode only, existing Curator's quote/FrizzleQuestion contract still applies.

### B. SEMANTIC / DOCUMENTARY COLLAGE · optional complementary core
Provenanced quotes, archival context, false authority, counter-frame, satire, Warburg neighbors, evidence vs fiction, temporal associations; may feed A but never veto an independent A composition for lacking documentary value.

### C. INTERACTIVE / SPATIAL MONTAGE · complementary core
Rabbit-hole branches, motif recursion, world billboard/immersive switch, spatial layer transitions, biome and card associations, player-chosen exploration. May modulate A and B; does not replace their artistic autonomy.

## Alternative output modes to stop accidental scope collapse
1. **PURE_VISUAL** — autonomous image/typographic/optical cinema, no Card/quote required.
2. **MUSIC_VISUAL** — music-led composition through existing H13 analysis and KFB Audio consumer.
3. **VISUAL_DOCUMENTARY** — collage and sourced fragments, with explicit source provenance for factual assertions.
4. **INTERACTIVE_RABBIT_HOLE** — navigable media sequence using typed semantic/artistic links.
5. **DIEGETIC_MEDIA** — playback on existing world billboard/3D screen; same source, no second host/render loop.

These are **creative mode labels for future consideration**, not approved runtime modes/schema. Do not add new controls/navigation to live interfaces based on this paper.

## Source reuse and failed-v0 nuance
- **H13's actual visual body is the initial donor**. According to current H13 source docs it already contains film/public-domain layers, FOIA plates, sprites, Card images, fractals, hypno patterns, formulas, moving typography and signal-reactive flashes.
- H4 H13 source and output must be **visually isolated** before integration. A file load, link or successful import is not evidence the visual result matches.
- H13's distinct **Engine v0 was failed due to poor art direction / indiscriminate all-parameter dice**, **not** because generative visuals, randomness, flashes, noise, extreme transitions or abstract collage are forbidden.
- Prefer **constrained combinatorial art direction**: purposeful material clusters, editable rhythms, compositional contrasts, source-literate image transformation, curated surprise plus bounded/seeded generative mutation. Randomness can be the point in artist-chosen regions.
- One existing renderer/clock/music owner; any GPU/CPU code transformation is a module/adapter under that owner. Source reference isolation before donor integration.

## Creative acceptance samples (all PROPOSED / NOT EXECUTED)
- **V1, 10s autonomous cinema loop:** collage + typography + optical effect + hard cuts/intentional flashes, no required quote. Freeze source frames, loop point, output review. Need image not a dashboard.
- **V2, 10s hypnotic/generative loop:** feedback/moire/spiral/slitscan from real source module, legible kinetic form and deliberately varied intensity. Distinct from V1.
- **V3, 30–90s experimental music film:** evolving sections (including silence/sparse visual rest if artist chooses), strong change of register and purposeful surprise; compare against H13 baseline on same source song.
- **V4, optional semantic hybrid:** only after first three stand as real art. Introduce source/context rabbit-hole as a creative extension, not prerequisite.

### Test semantics
- Human visible evidence: actual motion capture/film of isolated *H13 original* and generated candidate, not screenshot of HTML loading. Show at 10-second duration as requested for motion studies.
- Qualitative independent criticism: compositional variety, expressive intensity, genuinely filmic editing, interesting collisions, recognizable donor DNA, absence of stock AI wallpaper, artistic control and deliberate transformations.
- Actual output measurements only when run: frame timings, dropped frames, shot durations, audio sync/latency, texture/update bandwidth, seamless-loop variance, effect toggles. Never fabricate FPS or motion results.
- For visually intense sequences, author-selectable intensity and reduced-motion alternative can coexist without sanitizing the intended main artwork. Deliberate flicker is NOT blanket-banned.
- No requirement that each visual cut has a documented neighbor edge; graph evidence is required only when *making factual documentary claims*, not for free artistic association.
