## Why this plugin exists

Before conducting research on an author, subject, interview, book or source, the skill:
1. checks current authorized GitHub corpus, source ledger and backlog;
2. discovers already available Google Docs / Drive source text, keeping original revision provenance;
3. checks *NotebookLM* source inventory **only where a real connected action or user-supplied export allows access**;
4. splits existing reviewed coverage from missing original passages, new publications, contradictions and current source updates;
5. generates a **targeted Perplexity or NotebookLM deep-dive prompt**, excluding redundant basic research and explicitly preserving existing source IDs;
6. prepares a sourced, additive, reviewable patch and permitted GitHub/authorized site handoff;
7. never adds fictional/performance/Game/Card/Triplet/Borromean/stand-up content to the source worldview.

**Project-neutral:** The default skill does not require KFB, a KFB repo, KFB Cards, Site, World-building lore, or Production Control. Users can provide a different project/repo/source owner. This checked-in folder is an audit/recovery mirror, not a new global SSOT. The plugin installed label is a brand, **not** a license to inject a KFB comedy layer.
