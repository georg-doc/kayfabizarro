# TheWebb free public benchmark — C03

Date: 2026-11-01. Scope: free public page, no sign-in, purchase, trial, account creation, private-file upload, API/MCP invocation or paid query.

Source: [Lizzie Borden public dataset guide](https://www.thewebb.io/datasets/lizzie-borden). TheWebb platform is distinct from Gary Webb and Whitney Webb. It is a potential external discovery service, not the Atlas source owner.

## Observed directly

The browser rendered the public guide. Its witness/timeline section presents differentiated accounts and page-specific source links. Opening “When Mr. Morse left” displayed conflicting reported times; returning via “Back to the stop” restored the witness passage. One screenshot of the comparison was visually inspected. No source-document page image was inspected. A locator-based uncheck found no matching control; the visible back button worked. This is a bounded UI interaction test, not whole-product QA.

The cited police-statement link has a PDF `#page=8` target. Its separate web-tool fetch was inaccessible; PDF delivery and historical content are NOT verified here. The page explicitly identifies modern transcriptions and OCR, which must not be relabelled original handwriting. A text-only web extraction reported 2,780 pages while the rendered page displayed 5,386: vendor counters are not independently audited or used as acceptance evidence.

## Useful receiving pattern

For the existing Atlas, preserve a selected claim beside its reporting work, original record, exact locator and disagreement. Show different evidence scopes rather than drawing one undifferentiated connection. Page-specific links, dates and edition labels should survive Notebook export. This sample supports a comparison interaction pattern; it does not prove an authenticated network canvas, semantic search or AI-answer quality.

MCP remains an advertised capability in the existing benchmark, not a verified endpoint, access tier or tool schema. No free API allowance established. The research can continue without a provider subscription. A later read-only connector test would require official authentication/tool documentation and a clearly bounded public question; paid access remains outside this slice.
