# Journalistic source chains — first NotebookLM / Atlas packet

Research question: **What does a journalistic work actually establish, which original record supports it, and where does interpretation exceed the inspected evidence?**

This is a source-method comparison across six authors, not a claim that they form one historical organization or share one worldview. The original source masters remain in `authors/`; the receipt packets remain authoritative for this slice. Exported reader/graph files are derived views.

## Use

- Import `NOTEBOOKLM_READER.md` as a Markdown file into an explicitly selected notebook. It is a compact reading aid, not an original document or independent corroboration.
- `PUBLIC_SOURCE_URLS.txt` lists the actual research URLs. Import selected originals separately where accessible and permitted; a URL list or dossier link does not automatically import those originals. Review import results individually.
- `atlas-source-chains.json` connects author → work/source → attributed claim → comparison record, with exact IDs, scopes and uncertainty. It is prepared input for the **existing** Atlas, not a deployed replacement runtime.
- `GEMINI_NOTEBOOK_INVENTORY_PROMPT_DE.md` produces a separate, access-bounded metadata inventory for reconciliation. Keep private output private. `NOTEBOOK_RECONCILIATION.md` records current connector discovery and the subsequent additive matching process.
- `THEWEBB_FREE_REVIEW.md` records a public-page interaction benchmark. No paid access or authenticated query tested.

## Five starting questions for NotebookLM

1. Which original documents were actually inspected, and which works remain catalog or index leads?
2. How does the scope of an official investigation limit what it can corroborate or contradict?
3. Which apparent independent sources share the same report, witness or publisher root?
4. Where do publication date, event date and later transcription/edition differ?
5. What additional document would most sharply change each provisional assessment?

Always answer with source IDs and locators. Mark unknowns, preserve attribution and distinguish institutional reports from an omniscient verdict. An author biography, bibliographic entry or normative code does not verify all of an author's reporting.
