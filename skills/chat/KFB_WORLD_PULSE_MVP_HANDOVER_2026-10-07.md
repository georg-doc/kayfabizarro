## Product intent

The KFB world should read as a **breathing, living toy**, not static scenery plus animated characters.

Use one shared low-cost presentation layer:

`BaseLife + Wind + Music + optional EventPulse`

Do not create a second Audio runtime or per-prop analyser.

## First useful proof

For the current bounded Island MVP, do not fan out everywhere.

Prove exactly:
1. one KayKit Nature/Forest **clustered foliage family** (bush/canopy/crown, not isolated leaves);
2. wind-driven cluster sway;
3. the same cluster receives subtle music modulation from the existing Audio owner;
4. one hero prop/landmark secondary-soft group also reacts;
5. one local Jukebox or Billboard/signature source creates a stronger bounded response field;
6. one global soundtrack can provide a weaker scene-wide response;
7. existing AudioContext / MusicClock / mixer remain the only owners;
8. performance remains inside the current product gate.

## Cheap implementation rule

Audio exports one read-only semantic pulse:
- beat/downbeat phase;
- broad music energy;
- audible intensity;
- active source IDs/gains.

World supplies source positions/radii and wind state.

World Pulse sends shared uniforms to instanced vegetation/props.

Per instance use:
- stable phase seed;
- amplitude/stiffness;
- wind sensitivity;
- music sensitivity.

No per-object FFT, no unique material per plant, no offscreen CPU motion.

## Motion taste

Do not build a literal equalizer forest.

- bass → small grounded pulse;
- rhythm → short sway accent;
- strings/pads/harmony → broader breathing/sway;
- melody/high texture → subtle tip flutter;
- crescendo → wider but bounded response.

Orchestral music should feel atmospheric, not like disco pumping.

## Residents / band

Resident Performance remains owner.

Band and dance clips may sync to beat/bar boundaries when already in a performance activity.

Ambient Residents do not automatically dance.

## Visual rule

Claybound remains the visual Gold Standard.

Music response must make the world feel more alive **without** breaking contact, silhouette, readability or toy-world cohesion.
