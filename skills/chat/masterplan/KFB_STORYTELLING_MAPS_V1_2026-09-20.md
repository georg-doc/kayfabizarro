# Masterplan Addendum · KFB Storytelling Maps v1

Date: 2026-09-20
Status: **CURRENT REFERENCE / EXPERIMENTAL DIRECTION**

## Decision

Evolve the existing KFB Cartoon Map Board into **KFB Storytelling Maps v1** as a reusable presentation/authoring layer for:

- world/zone/galaxy maps;
- tactical board scenes;
- cinematic story maps;
- game cut-scenes;
- later editor/authoring workflows.

This is a product direction over the existing implementation owner, not a second runtime.

## First proof sequence

```text
Europe P0.2 technical baseline
→ T1 exact BoardGameBits / dice donor isolation
→ T2 media standee
→ T3 KFB standee motion
→ T4 physical dice impact
→ responsive camera/story runtime
→ Odyssey 2–3 min cinematic POC
→ Near East / contemporary tactical demo
→ authoring editor
→ named consumer integrations
```

## Cross-project reuse

- KayKit BoardGameBits: physical tabletop language.
- KFB Cartoon Animation v2: choreography and camera/VFX discipline.
- FrizzleBob Driver Graft + Rig_Medium animation pool: 3D guide/narrator.
- Audio/Card and Board: tactile board SFX.
- FX_Visual: VFX source pool.
- OSM/Map Board: geography.
- CardBuilder: later real KFB card surfaces.
- Game Development Studio: optional package/evidence/performance support.
- Build 3D Game Rooms: optional diorama/room cutaways only.

## Benchmark

Ludo Wala is recorded as a concept/UX benchmark for:
- physical tabletop feel;
- responsive camera;
- tactile die;
- dynamic light/shadow;
- spectacle separated from canonical state;
- mobile-first board interaction.

No code or proprietary art is reused.

## First authored story POC

The Odyssey is selected as the first proposed cinematic test because public-domain art and a journey narrative can prove the engine before contemporary/political editorial use.

Exact asset ingestion remains gated behind T1/T2.
