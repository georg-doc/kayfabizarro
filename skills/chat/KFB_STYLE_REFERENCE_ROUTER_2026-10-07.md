## D · Design-agent read rule

When a Design/Blender task touches KFB look:

1. read the receiving product/feature SSOT;
2. read this router;
3. inspect the relevant Styleguide section;
4. inspect individual broad Style References only as needed;
5. show exact source donor/reference before adaptation;
6. state which reference is:
   - BINDING,
   - BENCHMARK,
   - MOOD/INSPIRATION,
   - HISTORICAL.

Do not say only "KFB style".

## E · Critic usage

A future visual critic should receive a small **task-specific reference subset**, not the whole corpus.

Examples:
- shield/character fit → source promo + source asset + gameplay-distance silhouette benchmark;
- track → `02_strecke` + Joyride exact donors;
- world palette → `00_referenzblatt/01-farbpaletten` + receiving biome recipe;
- clay → source object + Golden + candidate;
- HUD → `04_hud` + product UI contract.

This keeps critic comparison precise and cheap.
