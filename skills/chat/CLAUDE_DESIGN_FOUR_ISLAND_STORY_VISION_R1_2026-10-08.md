# 4 · What the vision must communicate

Every island must communicate, visually and spatially:

`history / origin`
→ `geography`
→ `settlement / institution`
→ `roads and paths`
→ `buildings / landmarks`
→ `Residents and daily activities`
→ `present-day life`.

The viewer should understand a place, not a checklist.

No road, bridge, market, landmark or major building may exist merely because a feature list names one.

---

# 5 · Direction A and B

A and B are **not two different stories**.

They are two visual/spatial interpretations of the same recovered canon.

They may differ in:
- silhouette;
- spatial hierarchy;
- architectural massing;
- degree of density;
- composition / negative space;
- how story scars are staged;
- how surreal vs grounded the toy-world presentation feels;
- how highways/connectors are visually integrated.

They may **not** differ by inventing new lore, replacing Residents, changing the Golden Journey or assigning arbitrary new institutions.

# 6 · Required visual package per direction

For **Direction A** and **Direction B**, provide:

## V1 · Four-island world overview

One strong **illustrated / concept-art world view** showing:
- KFB Town as historical hub;
- Utopia;
- Dystopia;
- Protopia;
- relative visual identities;
- meaningful connections between them.

This is not a technical node graph.

It should already make the four worlds feel authored and distinct.

## V2–V5 · One Island Story Board per island

Create one **high-quality concept board image** for each island.

Each board contains visually integrated:
1. a hero 3/4 perspective;
2. a readable top-down / oblique composition inset;
3. one daily-life / street-level vignette;
4. a small history/scar/detail inset.

Do not make four generic moodboards.
Each board must show one functioning place.

### KFB Town board must visibly contain

- a real market / social center;
- public/civic life;
- compact circulation / distributor where it serves the town;
- meaningful walking connections;
- connection toward the three satellite worlds;
- traces of settlement history / mine / institution / accumulated use;
- Town architecture as one coherent family;
- King Kayfabian civic/royal layer only where spatially justified;
- no generic medieval-town substitution;
- no road loop that cuts the social center apart.

### Dystopia board must visibly contain

- a world shaped by crisis/trap history rather than generic dark scenery;
- Orc Band + Resident Disco + Demon Lord birthday as a plausible lived/performance location;
- visible alarm / broadcast / crisis-loop language;
- a route network that works as a place;
- no meaningless "No-Off-Ramp" road defect;
- some visible contradiction between spectacle, control, fear and social life.

### Utopia board must visibly contain

- Robot A / Robot B actually doing work / repair / construction;
- Monstrosity CEO as visible center of authority;
- stepped pyramid/throne or another source-consistent power staging;
- clean engineered public face;
- maintenance/backstage truth readable somewhere;
- technology / automation / access / Terms-and-Conditions culture visible in the built world;
- not an empty sci-fi plaza.

### Protopia board must visibly contain

- Farmer Duo integrated into the world;
- farming + repair + workshop + communal life;
- visible seams / additions / hand-built infrastructure;
- activity routes that explain paths and spaces;
- social / market / storage / work relationship;
- nature + making, not generic pastoral idyll;
- Lorekeeper relation may be indicated where source-backed;
- older patched-island / workshop / mill / self-built bridge ideas may be explored only as proposal-level visual donors.

# 8 · Daily-life requirement

Each island board must show at least **two concrete daily-life relationships**.

Examples of relationship form:

`Resident → home/work/resource → route → social/market/place`

not merely:
`NPC standing near prop`.

The purpose is to make the world's topology emerge from life.

For example, Protopia may visibly make the chain:
Farmer home → field/resource → transport → workshop/storage/market → social stop.

Do not treat this example as a mandatory literal layout for every version.

# 10 · Visual quality bar

This is a **visual design task**, not an information-design task.

Do not return:
- wireframe SVGs as the primary artifact;
- generic boxes/arrows;
- low-fidelity flowcharts;
- code-generated schematic maps as the end result;
- placeholder architecture;
- generic stock-fantasy villages;
- four palette-swapped versions of one island;
- one generic circular island with different props;
- text-heavy documents with tiny images.

Use actual visual world-design craft:
- composition;
- silhouette;
- spatial hierarchy;
- scale;
- foreground / midground / background;
- lived-in clustering;
- sightlines;
- negative space;
- architectural rhythm;
- path purpose;
- activity staging;
- visual storytelling.

The top-down component may be diagrammatic **inside** a strong concept board.
It may not replace the visual concept itself.
