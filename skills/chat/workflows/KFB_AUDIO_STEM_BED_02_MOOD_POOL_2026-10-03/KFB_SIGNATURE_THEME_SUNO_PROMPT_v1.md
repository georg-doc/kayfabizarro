# KFB Signature Theme · Suno Authoring Prompt v1

## Working title

**BEETLE RUMBLE · KFB Signature Theme**

## Main generation prompt

118 BPM instrumental cartoon-series opener that fuses rockabilly drive, cosmic surf guitar, electro-funk, psychedelic disco and a slightly absurd wrestling-arena swagger. Immediate hook in the first two bars: a short, extremely memorable 5–7 note riff built from a D minor-pentatonic / bluesy Mixolydian palette, first played in tight unison by spring-reverb twang guitar and clipped clavinet, later re-orchestrated by bass, analog synth and short brass/organ punches.

The groove must be danceable and physical: punchy rockabilly kick/snare, occasional tom accents, restrained shaker/hand percussion, slap/boogie-style electric bass with a funky two-bar pattern, muted guitar scratches, warm Wurlitzer/Rhodes stabs, Hammond-style organ support and small electro-funk synth accents. Add surf tremolo, slapback echo, spring reverb and brief psychedelic tape/phaser gestures, but keep the rhythm section dry and forward.

Structure like a strong animated-series opening theme, around 45–70 seconds:
- immediate signature riff;
- 8-bar groove statement;
- exaggerated 1-beat stop / cartoon punch;
- second statement with funkier bass and clavinet;
- short cosmic-surf lift;
- 4-bar electro-disco / wrestling-arena peak;
- final return of the signature riff and a clean decisive sting ending.

The personality should be exuberant, slightly over-the-top, weird, funky and mischievous rather than cute. Imagine a ridiculous beetle-wrestling entrance, a cosmic roadside carnival and a psychedelic hot-rod cartoon sharing the same theme. The hook must survive if played by only one instrument.

Strong negative space around signature hits. Avoid constant lead melody. Avoid generic superhero orchestration, ska, swing big-band cliché, pop-punk, EDM build/drop, metal shredding, xylophone, marimba, vibraphone, bells, cute mallet sounds and glossy cinematic risers.

Instrumental only. No vocals, chanting or spoken samples.

## Stem goal

Prefer cleanly separable:
- Drums
- Bass
- Guitar
- Keyboard / Clavinet / Rhodes / Organ
- Percussion
- Synth
- Brass / Other FX

The **Guitar + Keyboard/Clavinet** stems should carry the clearest statement of the signature hook.

## Authoring goal

Generate 2–4 variants and select the version with:
1. the most memorable hook after one listen;
2. the best danceable bass/drum pocket;
3. a hook that still works when most other stems are muted;
4. clean section boundaries;
5. enough negative space for cartoon SFX;
6. no annoying bright/plinky timbre.

For the winner:
- export full stems;
- export MIDI if Suno provides a useful extraction;
- keep the exact BPM in the folder name;
- preserve master + prompt + source/version metadata together.

## Optional short ident / sting prompt

Create a 10–15 second instrumental ident derived from the same hook and instrument language: spring-reverb surf guitar + clavinet unison signature riff, funky slap/boogie bass, one rockabilly drum fill, a brief electro-funk synth response and a final exaggerated stop/sting. No intro buildup. Immediate recognizable hook, one variation, final hit. Instrumental only.
