## Human product direction

- v3 should preserve what makes Card Zone Lab v2 a real KFB world:
  - real card/deck/reveal;
  - sky card / projection language;
  - card-seeded palette / biome / story mode;
  - Card Cube / face-focus seams;
  - world/zone semantics;
  - fluid / river ideas where the later hex adapter proves them.
- Ground/world language for the new Project-Island mode is based on **real KayKit hex geometry**, not generic voxel boxes.
- Level 0 starts from a **three-project-hex safe platform**.
- Quick wins / low-hanging-fruit projects are reachable by one friendly assisted jump.
- lower level bands may hold archive/failure material, including a **Graveyard** class for post-mortems.
- project hexes are color-coded through a deterministic palette contract derived from the current Cologne Race Option C color-map donor.
- project hexes can later be added/removed through Minecraft-like edit semantics, but edits operate on valid graph cells and never silently break current support/connectivity.
- one signature Resident + prop vignette may inhabit each accepted project hex.
- guided jump points/paths are world data, not painted arrows guessed from screenshots.
- Paternoster / spindle / skydome is a later vertical-circulation slice, not the first build.
