## Product goal

One small playable loop under a fixed KFB Stage URL:

1. enter one coherent KFB world zone;
2. walk as a verified KayKit/FrizzleBob actor;
3. enter a selectable vehicle and drive the current Race movement/contact engine;
4. hear the zone soundscape plus vehicle response;
5. encounter one Resident/card interaction;
6. enter one instanced activity through a portal/door;
7. return to the world with state preserved;
8. use Theatre Curtain Core for loading/entry/reveal, not a generic loading screen.

Re-fetch exact PR/branch heads, update status matrix, select one executable integration slice. No implementation.
