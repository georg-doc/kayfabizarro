## Defects and limits first

- The pit lane is a straight-road feature: the main road must run straight over its whole length (about 2 × 120 m + the box stretch). There is no pit in curves yet.
- The pit wall is the main road's own barrier set on the pit side and the lane's inner set, both at half size (side scale 0.5, about 2.2 m each). It is not a thin Kenney-style wall; that is a look question for the S4 edge atlas.
- Box anchors are still flat slabs. There are no garages or pit building yet (scenery layer).
- The landing start still shows the underside as a dark sloped face from a low camera. It is round in side view, but not styled.
- 280 / 280 tests pass. The count dropped from 282 because the pit branch now has fewer pieces and therefore fewer per-route checks, plus one new test.
