# Combat · nächster produktiver Gate

## Erst Recon, dann genau ein Build

1. Öffentliche Combat-Stage und aktuellen Arena-/CA2-Head neu prüfen.
2. Kernloop: FrizzleBob → zielen → schießen → Warrior treffen → Kill → Reward → Run Clear → Respawn.
3. Einzelne problematische Actors (z. B. Mage) bleiben HOLD und blockieren nicht.
4. Wenn der Kernloop stabil ist: genau **ein** nächster Slice wählen:
   - KayKit-Player/Enemy-Adapter mit vorhandenen EyeRig-/Motion-Profilen; oder
   - Melee mit einer echten KayKit-Waffe und vorhandener Animation.

Kein gleichzeitiger Legacy-, Melee-, Mage-, Spindle- und Open-World-Ausbau. Arena bleibt Gameplay-Owner; ToolBox liefert Actor-/Rig-/Motion-Profile.

Erfolg: eine spielbare Browser-Demo, nicht vollständige Figurenparität.
