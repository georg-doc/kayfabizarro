## What the original establishes

At the pinned source, FILAMENT is described as a compact kidney-like course with:

- a long opening/start run;
- dense arches that make the opening read as a low tunnel;
- a tightening double-apex section;
- smooth authored corner transitions;
- gentle vertical swell;
- banking derived from curvature;
- broad four-lane race width;
- bright readable edge rails / arches against a dark road;
- sparse crystalline scenery and large distant forms;
- a warm spectral band with a cool complementary accent.

These are observations about the benchmark, **not implementation inputs**.

## KFB interpretation · design first

For **Slice C**, priority order is:

1. **Option-C visual authority boards** — color, light, form, saturation, atmosphere;
2. **cool playable Track composition** — flow, rhythm, width, banking, ramps, tunnel, reveals;
3. **Dom / Rhine / Cologne recognisability** — hero anchors and spatial orientation;
4. **OSM geography** — useful real-world context and semantic truth;
5. **OMS / city architecture fidelity** — secondary during this first design proof.

The original FILAMENT palette is **not** a palette donor. It is useful only as evidence that strong edge contrast, tunnel rhythm and low-frequency color grouping can support speed readability.

## Cologne route freedom

The first KFB test track does **not** need to map 1:1 to Cologne streets.

Allowed independent route moves include:

- follow part of the Kölner Ringe;
- dive through a narrow street or alley;
- cut between city blocks;
- rise onto or above roofs;
- cross courtyards or plazas;
- use explicit elevated structures over OSM buildings;
- create a ramp/bridge reveal toward the Dom;
- run beside or above the Rhine;
- pass near HBF / rail context without pretending rails are ordinary roads;
- use a tunnel/underpass beat where it improves the route;
- reconnect to street-level segments where useful.

OSM remains authoritative for **where Cologne features are**, not for forcing every Track centerline onto a road.

When the route leaves the ground:

- use an explicit `STRUCTURE` / elevated Track representation;
- do not deform terrain upward merely to support the Track;
- preserve the landmark/building anchor below unless the design intentionally replaces it.

## Slice-C design target

Use FILAMENT only as a benchmark for **tempo and memorable route beats**.

Build an original KFB loop around the Dom with roughly this experiential cadence, not this geometry:

`strong opening → compressed/tunnel beat → fast reveal → tightening technical section → elevated or rooftop surprise → broad sweeper / Rhine or Dom reveal → clean return`

The exact order may change if the Option-C composition reads better.

## Acceptance question

The first test succeeds when the Track itself feels visually authored and fun **before** exact OMS city fidelity is judged.

The question is not:

> “Does the Track follow the real Cologne streets exactly?”

The question is:

> “Does this feel like a strong KFB Option-C race world that is unmistakably anchored in Cologne?”
