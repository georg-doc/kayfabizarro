# KFB Production Flow v2 · WSA Handoff

Status: PREPARED · USE ONLY WHEN A REAL WSA CAPABILITY GAP EXISTS

## Für Georg

WSA soll künftig nicht mehr „alles zusammensuchen“.

Bevor WSA startet, sind die Teile schon vorbereitet:
- Quellen;
- Messungen;
- Zuständigkeiten;
- funktionierende Kandidaten;
- eine kleine Integrationsaufgabe.

WSA macht dann nur noch den Schritt, den Coworker/Web wirklich nicht sinnvoll erledigen können.

## Entry requirements

WSA starts only with:

1. current Production Packet;
2. exact current repo heads;
3. working donor proof where relevant;
4. measurement/source evidence;
5. accepted or internally verified inputs;
6. closed repo/file scope;
7. one named WSA-only capability;
8. one smoke test;
9. one stop condition.

If item 7 is empty:
**do not use WSA.**

## Good WSA capabilities

- simultaneous local private multi-repo checkout;
- binary/file transfer unavailable through normal GitHub flow;
- OS/browser automation;
- local packaging/build seam;
- final cross-repo integration smoke;
- release artifact assembly.

## Not WSA work

- source discovery;
- donor archaeology;
- ordinary code review;
- routine adapter code;
- repeated visual repair;
- Hub cleanup;
- Claude Design recovery;
- measurement guessing;
- ordinary Review HTML.

## WSA start text

If the first integration transition fails, preserve evidence and stop.
