# Workflow · Visual QA

For each visible issue:

1. Capture the failing view and name the semantic read that fails.
2. Identify whether the problem is global world presentation or local actor/vehicle/tool presentation.
3. Compare with the named donor/reference if one exists.
4. Change the smallest owning layer.
5. Capture before/after from the same meaningful view.
6. Check adjacent states, not just the hero angle.
7. Record PASS / FAIL / NOT_TESTED / UNRESOLVED.
8. Visible acceptance remains Georg's decision.
