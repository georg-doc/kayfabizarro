## Binding user correction
**ONE semantic Triplet is ONE spoken sentence / utterance.**
`[subject] + [connector] + [reframe] → ONE sentence`.
The three semantic slots are NOT three successive sentences or separate stand-up paragraphs. An authoring sequence with eight Triplets consists of **eight sentences**, if all selected, not 24. Visual `flip-stagger` can reveal parts progressively, without redefining the unit. A meaningful middle relation is essential: the connector changes what follows, rather than being a filler contrast.

## Fractal extension, same semantics at different scales
1. **One Card → one Sentence**: smallest ChatterBox utterance; no LLM, input is pinned Card ID, presenter/resident biases select scene relevance. No automatic guarantee of natural grammar; start with audited compatible card phrases.
2. **One Page → micro-story**: up to 4 cards, several **one-sentence** Triplets or one actor/scene arrangement, card identities preserved. Page sequence uses the original PDF layout when meaningful, without treating each Card as a sentence slot.
3. **One Deck → local narrative**: deterministic sequential passage, seeded within-deck shuffle, or curator-picked sequence; card/page/provenance remains inspectable.
4. **Multiple Decks → Kayfabulation/Cut&Play**: combine Card identities and meanings, maintain source/deck contrast, invite human/player closure without synthetic generic aphorisms. Mixing can be deterministic and LLM-free; not every card pair yields an acceptable sentence.
5. **King Kayfabian Quest mini-game / full episode**: reuse the existing *proposed* framing: Actor Card + three Scene Cards + King's Quest Card, 3 scene slots, King/Quest Die, player-chosen connectors (BUT/THEREFORE, etc.), shared interpretation and finale. Reference `overworld/docs/LIVING_CONCEPT_overworld.md` §§39–41 and `Kayfabizarro_Freestyle_Rules_v18-4.md` for analog origin. **Do not claim the digital King's mini-game is already built**: `GOLDEN_JOURNEY_MVP_2026-10-04.md` lists it DEFERRED / not MVP-blocking.
6. Same Card ID can be consumed as NPC one-liner, POI, mini-quest, page micro-story, comic cut-up, Billboard or Almanac event; **card JSON remains SSOT**, not cloned into a replacement phrase bank.
