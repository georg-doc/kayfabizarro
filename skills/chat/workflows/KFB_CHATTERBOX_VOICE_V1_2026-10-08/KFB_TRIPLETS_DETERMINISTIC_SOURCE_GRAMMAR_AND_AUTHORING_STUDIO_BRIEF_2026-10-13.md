## Product concept and operating modes
Goal: source-heavy stand-up performance from KFB Cards as **one Card / a few Cards / a real PDF four-card page / a complete Deck**, with an LLM-free *runtime*. The spoken beats and non-trivial transitions must come from original Card text plus a **small curated semantic grammar / bridge library**. No recurring Work or paid LLM calls for new performances using previously admitted cards and vetted relation templates.
- **Extract/Cut:** source spans are exact, field- and offset-identified Card title/POWER/LORE phrases; artworkPrompt is semantic intent, not verified printed Card pixels.
- **Condense/Frame:** grammatical inflections, articles and reversible small connective glue may be used; every new concrete fact, named character, cause, object, role, setting or mechanical outcome requires a source anchor. Do NOT silently invent new motifs to make a story sound clever.
- **Triplet:** one spoken semantic unit, role-tagged `subject / relationPredicate / reframe`. Relation carries real rhetorical/causal function; reframe changes implication, allegiance, cost, certainty or interpretation rather than restating two other fields. The source roles are NOT preassigned to Card title/power/lore.
- **Bridge:** a separate inter-Card unit only when `beforeState`, `causalOrPseudocausalOperator`, `nextConditionOrTrigger`, `afterState`, `changedStakeOrCost` can all be shown with source lineage; the text is a short stage hinge, not a new canonical Card rule. For a surreal mismatching leap, explicitly type `PSEUDOCAUSAL_CLOSURE`, preserve audible but/therefore logic, and allow player/critic to accept/reject. If nothing grounded works, emit `NO_EDGE`, a marked edit/cut or silence.
- **Performance:** stable chain of Cards with continuity/callbacks, Story Mode/perf persona/intro/delivery/ending, actor timing and exact Card IDs. `Stay Fluffy!` is fixed final spoken line for Card performances; optional character-fitting Fluffhead greeting. The card's title and exact PDF identity remain metadata even if visual display makes reciting the complete title less useful.

## First make one compact production recipe, not 4,119 autogenerated punchlines
One-time editorial corpus onboarding per Deck (original JSON stays immutable):
1. Inspect exact original `deckId`, full Card count, source Card JSON blob, original PDF / verified registry Crop mapping. Enumerate all IDs, POWER/LORE nulls and nonstandard fields. No implicit default from named deck to 3 Cards.
2. Capture 2–5 **verbatim quotable spans per Card** if possible. Per span: `field`, original start/end offsets and exact text, lexical role (subject, action, target, condition, cost, contrast, turn, rhetoric), sentiment/story mode and whether it is already a punchline. Retain source author's syntax, including genuine weirdness.
3. Curate micro-operators with strict signature (e.g. `IF_TRIGGER_THEN_COST`, `PROMISED_WIN_BECOMES_LOSS`, `APPEAL_TO_AUTHORITY_REVEALS_SELF_INTEREST`, `ROLE_APPROPRIATES_PRIOR_WORD`, `NEGATED_ESCAPE`), plus grammatical surface patterns only. Operator must be able to display why a **specific original phrase** fills each semantic slot.
4. Compile a Card `TripletCandidate` by span selection and optional function-word morphing, never by abstract free-form paraphrase. Render one grammatical utterance; test visible subject, relation claim/predicate and reframe. If reframe cannot be formed, set `NO_TRIPLET` (the original Card may still be shown, captioned, or read verbatim).
5. Build a separate typed edge graph from `cardState` and `stageState`; match compatible trigger/target/cost or deliberately labeled pseudo-causal association that consumes a *specific* detail. Seeded selection only among vetted edges and backtracking that respects state. Never pick "but/therefore" at random as if it created causality.
6. An independently curated `PERFORMANCE` stitches accepted semantic units and hinges. The runtime uses pure data, deterministic seed, no LLM calls. Research/curation may use LLM in Web Chat **optionally**, but source comparison and a human editorial gate keep derived entries out of accepted pool until inspected.
7. Export three distinct products: (a) ChatterBox semantic Triplet records, (b) performance script + cue/card map + source proof, (c) Suno Lyrics/Style or Audio-local draft where **capability supported**. Keep accepted vs editorial candidates and original source immutable.

- Every derived text segment has `surfaceOrigin` (VERBATIM_CARD, GRAMMAR_GLUE, CURATED_OPERATOR, EDITORIAL_STAGE). Give separate strict verbatim %, source-anchored **semantic content**, unanchored factual claim count and new bridge words. A low verbatim % does not alone prove hallucination; a high % alone does not prove humor.

## First validation: semantic Golden/negative/real audio — no overclaim
Start with **a modest deliberately selected source sample**, from 2–3 real Decks with contrasting genres and edge compatibilities, not a full-volume autoplay. Include actual original sentences already funny and boring/unsupported Cards; select source/pairs before seeing model output, to prevent cherry-picking.
Tests:
- Check 100% Card IDs exact, every source content span via blob/offset, no fabricated rule/factual claim, no silent missing Card/page/deck, one source-anchored utterance/valid silence per selection.
- Label all Triplet `subject/relationPredicate/reframe` and ask independent critic whether the predicate carries meaning and reframe changes the conclusion. A title+Power+Lore synopsis must fail this semantic test even with 100% verbatim words.
- For each Bridge inspect `beforeState→actual transition→afterState/cost`, sourceRefs and *heard* hinge. Randomly relabeling a transition must not pass. Original 1001 Nights #5–7 **negative Golden** stays FAIL under regression without altering/re-auditioning its text.
- Track meaningful source coverage rather than impose unsupported magic threshold; aim to preserve **most informative words** of each Card with minimal glue and no new narrative facts. Record literal ≥3-gram and ≥2-gram overlap using the documented 1001 Nights method, but calculate **body vs intro/outro/bridges separately**.
- Evaluate blind side-by-side for comedy, economy, musical delivery, and distinctive character voice. If independent human critic/Georg rejects, `HUMAN_FAIL` overrides structural passes.
- Full-deck coverage is an **explicit later mode**. Under Suno's requested 5,000-character speech limit, a 60-Card deck has only roughly 80 characters per Card after intro/outro and bridges; split into multiple honest chapters if source fidelity/punchline quality cannot fit. Never silently omit 57 Cards.
- Determinism: given fixed admitted corpus+seed+actor/mode same output; changed approved span set changes only appropriate outputs. Runtime use must pass network-denied test with **zero LLM calls**.
