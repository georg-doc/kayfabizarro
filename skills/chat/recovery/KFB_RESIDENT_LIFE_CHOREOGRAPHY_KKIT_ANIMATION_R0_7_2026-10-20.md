## Timing / performance score (candidate, not frame-authoritative)
- TRAVEL: velocity driven by WS1 nav; locomotion clip rate blends to actual grounded motion; look-ahead turn bounded by support.
- ARRIVE: transition to stance when within owner-validated interaction radius and movement stopped; short anticipation/settle before prop contact.
- ACT: one meaningful action beat with exact sourced prop socket, collision and animation phase; occupancy held.
- NOTICE: gaze/orient then optional gesture; social invitation requires both actors interruptible and reachable.
- INTERACT: reciprocal encounter sequencing notice → approach/orient → greet → offer/receive or inspect → react → resolve; one event receipt for meaningful exchange, not one per frame.
- INTERRUPT: snapshot semantic activity+target+progress, release unsafe movement action, run priority reaction, choose RESUME/REPLAN/SEEK_HELP; never teleport, snap feet or re-trigger item grants.
- HIT later: only Combat-confirmed hit progresses R0.6 ladder; hit-stagger interrupt, face/emanata/bubble/sound merely depict event; release Fluff through current WS1 source.
- KO later: authenticated downed state, sourced collapse pose/ground contact and finite drop, same stable resident ID after return; animation doesn't write save/memory.
