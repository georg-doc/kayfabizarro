# R3 · Source Fidelity / Original vs. Adaptation (public method)

**Status:** ADDITIVE QUALITY RULE, NOT HUMAN_ACCEPTED.  
**Owner:** Philosophy Sparring Content only.  
**Privacy:** This document contains no personal manuscripts, author identities, titles, quotes or private bibliographies.

## Failure finding

An initial private manuscript probe mistakenly treated a condensed/adapted document as the original. The user's correction identified a different original. The earlier interpretation was therefore based on the wrong version and is **superseded as an account of the original author's position**. The source error belongs to our intake/analysis process, not to the author.

## Source hierarchy

1. USER_DESIGNATED_ORIGINAL: source truth for the present task, subject to optional external authentication only if requested.
2. AUTHOR_REVISED_VERSION: dated revision with its own provenance; neither version silently erases the other.
3. EDITORIAL_ADAPTATION / LLM_REWRITE: derivative, not automatically reliable for original wording, emphasis, or author biography.
4. ASSISTANT_ANALYSIS: interpretation, never a primary source.

## Required checks

- Read the whole source or state exact coverage; inspect opening **and** substantial middle/late argument sections.
- Compare key theses, argument dependence, evidence, counterclaims and what was omitted; not merely chapter count or word count.
- Check both structured Word footnote/endnote XML and visible manually numbered lists; verify references independently.
- User correction overrides any prior assumption; explicitly retract incompatible earlier conclusions.
- Do not derive personal worldview, intellectual rank, or preferences from an editorial adaptation.
- Keep private file titles, contents, hashes, personal author data and bibliographies **outside public GitHub** unless permission is explicitly provided.

## Nontriviality refinement

A change of source version can reverse the apparent focus of a philosophical work. Trace which epistemic, hermeneutical, ethical or theological commitments the derivative suppressed or invented. A new research lead must follow from the **actual reasoning structure**, not merely from an easy dialectical antithesis.

A cross-author comparison should differentiate original text observations, model reconstructions and external academic scholarship. A link to a resource is not proof that the cited passage was checked.

## New Golden expectations

G10: an editor's rewrite was mistaken for an author's original, later corrected.
G11: real structured footnotes in one version vs absent notes in the other.
