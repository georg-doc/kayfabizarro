# Generated KFB Asset Registry v1

This directory is generated by `tools/asset_registry/build.py` plus the AR5 `tools/asset_registry/rigfacts.py` sidecar builder, and validated by their validators.

**Implemented pipeline:**

- AR1 deterministic flat inventory
- AR2 structural packs + explicit model dependencies
- AR3 explicit adapter for the existing `media/kfb/kfb-index.json` deck contract
- AR4 deterministic delta + validation + GitHub Action / bot PR refresh
- AR5 deterministic rig/animation facts + neutral consumer query/handoff

A real repo build creates:

- `manifest.json`
- `catalog.jsonl`
- `summary.md`
- `problems.json`
- `delta.json`
- `rigfacts.jsonl`
- `rigfacts-summary.json`
- `kinds/*.json`
- `packs/index.json`
- `packs/<pack-id>.json`
- `decks/index.json`
- `decks/<deck-id>.json`

Do not edit generated records manually. Curated pack/dependency exceptions live under `tools/asset_registry/overrides/` with explicit provenance. Deck ownership remains with `media/kfb/kfb-index.json`.

Rig facts are structural file facts only. They do not assert retarget, gameplay or donor compatibility. `tools/asset_registry/query.py` can wrap selections in a `kfb.asset-handoff.v1`; every such selection remains `candidate-only` until the receiving consumer validates it.

The `Refresh KFB Asset Registry` workflow updates this directory only through the workflow-owned `bot/asset-registry-update` branch and a reviewable pull request. It never writes generated Registry changes directly to `main`.
