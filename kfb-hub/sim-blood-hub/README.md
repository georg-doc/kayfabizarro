# SimBlood Hub

Canonical visual project overview for the SimBlood morphology/asset lanes.

Public route:
https://kayfabizarro.pages.dev/kfb-hub/sim-blood-hub/

## Visible UI

Resting gallery:
- image
- cell name
- full-word group filters only

No visible IDs, priority codes, source-registry metadata, licence copy, coverage stats or explanatory paragraphs.

## Cell detail

Each cell opens as a deep-linkable page state (`#CELL-ID`) with collapsible visualization lanes:

- **Mikroskopie** — morphology references + real/open candidate cells
- **SimBlood** — runtime POC / review surfaces
- **3D** — interactive 3D morphology work where available
- **Synthetisch** — CytoDiff or controlled-generation lane

Concrete samples show compact source + intended use.
Missing lanes stay visibly open as small planned slots; no image is invented to make the hub look complete.

## Initial scope

Representative project overview, not yet the entire 80-entity taxonomy:
- 3 RBC morphologies
- 5 mature WBC classes
- 2 platelet classes
- 2 precursor/pathology cells

The data model is intended to expand toward the full taxonomy without changing the UI pattern.
