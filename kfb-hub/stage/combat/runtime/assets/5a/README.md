# Prop-Quellen · Arena v5a

Alle Modelle stammen aus den vom Nutzer bereitgestellten Assets im Repository `georg-doc/kayfabizarro`. Genaue URLs, SHA-256 des heruntergeladenen GLTF, enthaltene Clip-/Materialnamen und lokale Abhängigkeiten: `manifest.json`.

Aktiv: `healing-potion`, `water-bomb`, `smoke-bomb`. Nur vorbereitet: `chest`, `knife`, vier `pencil_*`-Varianten. Keine dieser GLTF-Dateien enthält Animationsclips. Modelle bleiben im Original; Bomben-Farbgestaltung erfolgt pro Instanz in der Arena.

KayKit Dungeon und Adventurers: Kay Lousberg, https://kaylousberg.com. Beiliegende CC0-Texte unter `licenses/` aus dem jeweiligen Pack übernommen. In den überprüften Packwurzeln für RPGToolsBits und Platformer lag kein Lizenztext; dafür wird hier keine eigene Lizenzzusage ergänzt.

Die GLTFs und ihre Buffer/Texturen sind lokal gebündelt, damit beim Spielen nicht pro Pickup erneut auf GitHub zugegriffen werden muss. Dateizugriff erfolgt beim Laden der Templates, Klonen erst beim Spawn.
