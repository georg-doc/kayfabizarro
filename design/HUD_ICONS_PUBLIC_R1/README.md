# KFB HUD Icons · public package R1 (WS0, 2026-10-27, V-881)

Public copy of the HUD icon brief so that an external design model can read it. Start with `PROMPT_CHATGPT.md`.

- `sheets/props_sheet.jpg`: 53 backpack items, all rendered the same way (orthographic 3/4 view, one light rig, clay look, kit colours kept).
- `sheets/weapons_sheet.jpg`: weapons from the free KayKit packs (Fantasy Weapons Bits, Adventurers 2.0, Skeletons) and the free arsenal pieces.
- `renders/`: each item as a single PNG, 512 px, transparent.
- `BRIEF_HUD_3D_R1.md`: the earlier 3D prop HUD brief (round R1).

Purchased models and private HUD props are not in this public copy; they stay in the private game repo.


**R2 (27.10.):** every prop is now rendered at one uniform 30° tilt (Georg: icons fit the slots better, and found items float at the same tilt in the game). Use `renders_r2/` and `sheets/*_r2.jpg`; `renders/` and the R1 sheets stay for history.
