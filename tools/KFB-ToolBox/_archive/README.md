# ToolBox · Release-/Dokumentationsarchiv

Für benannte, ersetzte ToolBox-Releases, frühere Auftragsstände oder aufgegebene Arbeitszweige, nicht für aktive Eingänge. Bearbeitete Eingangs-Jobs gehören nach `../_inbox/archiv/`.

Ein Archivstand braucht Quelle/Commit, Status, Nachfolger, Gründe und Rückweg. Existierende Onboarding-/Quellpfade nicht still verschieben. Der Export `WSA_2026-09-13` bleibt für T1 an seinem bisherigen Pfad, solange Consumer darauf verweisen.

Keine Massenbereinigung, keine Archivierung nur wegen alter Versionsnummer. Zuerst Nutzung/Owner prüfen und aktive Referenzen erhalten. Historische PASS bleiben auf ihre damalige Revision begrenzt.
