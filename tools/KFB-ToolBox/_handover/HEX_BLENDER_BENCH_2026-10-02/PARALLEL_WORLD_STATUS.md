# Parallel World status for the Hex Blender bench

This note reconciles the parallel chats that were partially hidden by timeouts.

## 1. Universal material / Clay

Current recorded product direction:
- **`clay_floor_001` = best visual lightweight/global candidate** in Georg's latest same-geometry comparison.
- the heavy procedural Clay path is visually useful but expensive; representative WC1 measurements showed the Clay fragment path as the dominant cost.
- `Clay002` was fast in the lightweight pack but failed the visible material-identity test at 6/9/12 m and is now a negative/control state.
- Derek RGB remains a useful comparator, not the selected default.

Important measured context from WC1:
- heavy procedural Clay: about 27.73 ms in the Global-Clay-Lite comparison sequence;
- `clay_floor_001` lightweight candidate: about 12.99 ms in that sequence;
- Clay off: about 11.16 ms.
These are same-sequence browser measurements, not Blender predictions.

For this Blender bench:
- use `clay_floor_001` as the **primary lightweight material comparison**;
- keep neutral source material as the control;
- do not invent another Clay shader;
- do not claim a final runtime win until the later browser check.

## 3. Procedural buildings

No generic procedural building implementation is accepted yet.

The next building step is a **normal building-family specification from existing Golden donors**, not freehand "wonky houses".

Binding deformation lineage:
1. Elastic Grotesque
2. City Grotesque / Cartoon-Verbieger
3. LandmarkElastic
4. cumulative height-dependent LOOK-TORSION
5. existing semantic FACADE_RULE

Style grading:
- Polly & Her Pals = designed perspective / graphic distortion
- Rocko's Modern Life = everyday architecture becomes cartoon-alive
- Metropolis = hierarchy / monumental massing / bridges / skyline rhythm

Blender should therefore:
- identify good authored building-family seeds;
- measure them and their material/mesh structure;
- prepare evidence for the first building family;
- **not** invent the final procedural building generator in this bench.

## 4. Biome / composition

Do not start a second biome/scatter system.

Reuse the existing evidence:
- KayKit family size bands;
- Travel cluster grammar;
- one leader + smaller companions;
- grass in 3–5 blade clusters;
- mushrooms as 2–4 family patches or stump detail;
- T3 Rule-of-Three nature grouping as one proven cluster recipe.

The Blender scenelets may encode density/role suggestions, but placement/runtime ownership remains outside Blender.

## 5. What this changes in the Hex bench

The bench is not simply "which of 447 GLBs are cheap".

It must compare:
- authored Hex/KayKit modules;
- already-proven procedural nature families;
- the current lightweight universal material direction;
- authored building seeds that can feed the next procedural-building family;
- source-backed composition rules.

That is the current unified world direction.
