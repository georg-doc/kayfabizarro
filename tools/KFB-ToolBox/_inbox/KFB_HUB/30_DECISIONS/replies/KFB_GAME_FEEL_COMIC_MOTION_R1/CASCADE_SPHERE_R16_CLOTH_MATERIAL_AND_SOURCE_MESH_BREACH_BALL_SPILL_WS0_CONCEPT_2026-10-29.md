# R16 · Material Families (Rough Linen etc.) + Destructible Real 3D Source Buildings with Ball Spill
**29 October 2026 — Georg's additive KFB Game Design concept. No runtime work, shaders, mesh edits, source mutation, official V-962 update or Site.**
**Read with:** R13 HyperNorm Card Buildings/Gutter City, R14 correct *Gaussian Splats* (3DGS), R15 existing source-3D Material Modes. In this R16 **materialized source 3D model geometry remains source-accurate**. One **original fully rigged 3D FB_CANON** player, not a 2D standee. Existing R3F Host Contract R1.2 / CANON_3D / S5 façade rules / Track Core / Combat and Destruct authority remain owners.

## 1. Georg's idea (two additions)
1. Reuse actual KayKit/Kenney 3D buildings and props as stylized Normalization/HyperNorm containers, but change the **material feel** per category (e.g. *coarse linen/canvas/hessian cloth wrapped around a real 3D building*). All share KFB palette, clay light/shadow, HyperNorm/terrain-flow harmonization, source-faithful shape. The pavement might be rough clay stone with readable relief while a neighboring building is visibly woven linen: **same world, different tactile surface**.
2. Apply the **same shot→damage→aperture→colored interior ball spill→gutter flow→repair** rules to actual source 3D buildings as to the earlier rectangular HyperNorm Card Buildings. Try temporary/rebuildable, large holes in original building shell, perhaps source-colored beads and optional 3D Gaussian-splat interior visible behind. Reuse existing Destruct authority/cell system rather than performing arbitrary live polygon boolean surgery on every asset.

- `tools/KFB-ToolBox/_inbox/KFB Seed World Mech Destruction POC 01/KFB_SEED_WORLD_MECH_POC_01_2026-10-06/seedworld/sw-mesh.js` has `BuildingRecipe → same geometry/cell ids`, `cellsFor()`, damaged LOD compilation and intact/source-compatible repair. `seedworld/sw-destruct.js` supports promotion `INTACT_COMPILED → DESTRUCTIBLE_LOCAL`, authored wall/floor/roof cells, hits, detachment, bounded debris/rubble/chips/dust pools, 2-bit states `pack2/unpack2`. **THIS IS NOT YET A GENERAL DESTRUCTIBLE-GLTF ADAPTER** and does not magically cut a true hole through arbitrary one-piece original KayKit meshes. Seed-World Open-World integration `seedworld/docs/INTEGRATION_OPEN_WORLD.md` source-protects original KayKit buildings, with destruct planned as conditional donor to Combat/World owner.
- Binding `tools/KFB-ToolBox/docs/CLAY_BUILDING_FACADE_ROUTER.md` and non-main prepared S5 preserve source hierarchy, windows/doors, pivots, anchors, scaling and source shading. R7 GLTF material-zone Atlas demonstrates many source pieces use **one shared texture atlas/material**, making "change just the wall" impossible without first measuring source node/UV/face masks.
- R14 Gaussian splats are **volumetric scene imagery inside a building**, NOT the rolling, physically collided colored clay balls. They may be revealed by the same breach/door but require independent renderer/depth sorting/source dataset and cannot supply the collidable inner world by default.

## 3. Shared palette, deliberately different physical surfaces
**Materials are receivers/profiles under one existing KFB material/look owner, not a new global shader core.**
| Candidate profile | Original receiver | Appearance | Where to avoid |
| --- | --- | --- | --- |
| `PAVEMENT_CLAY_STONE` | current Track Core + Joyride sidewalk/kerb source | coarse clay stone, relief, quiet mineral noise, pale paper/ink edge, stable road readability | never fake street colliders by shader extrusion |
| `BUILDING_ROUGH_LINEN` | original GLTF source walls, roof selected only where sensible | visible woven coarse natural fiber, higher roughness/normal microrelief, low sheen, KFB palette tinted and sparsely animated bands | protect window glass, door signs, details and source material groups |
| `BUILDING_KFB_CLAY` | source building walls/roof | K2 clay organic soft print/grain and existing light/shadow owner | keep original source roof/body silhouette and support |
| `BUILDING_HYPERNORM_CLOTH` | selected hero curtain, tower wall or panel of original building | source cloth normal/roughness plus low-frequency moving colorbands and a framed, **legible** live H13/H14/H15 visual window | cannot stretch/crossfade arbitrary semantic cards across non-UV coherent source geometry |
| `HERO_CARD_VAULT` | one original building or generic HyperNorm cube | source card vault behind damage/aperture, source-colored ball reservoir, optionally bounded Gaussian splat pocket scene | actual 3DGS renderer/dataset only after source proof |

**Technical design:** one approved `paletteId`/`worldTime`/`lightRig`; per-node `surfaceProfile`, `sourceTexSet`, `uvScaleMeters` or measured triplanar static-object projection, `flowMask`, `animationRateTier`. For textured linen source normal/roughness/ao remain meaningful; tint base color and weight band overlay with `flowMask` instead of replacing whole material albedo. Original architecture/collider unchanged by this display role.
**Visual concerns:** coarse linen can read as miniature cloth on buildings and produce tactile contrast with stone. But texture repeats, seam discontinuity, hard UV borders, excessive normal amplitudes and moiré on distant facades will ruin it. Prove correct mips/aniso/roughness and close-up vs street-scale, moving original meshes need stable UV/object coordinates to prevent pattern crawl. Cloth *appearance* is not expensive deformable cloth simulation. If material sourcing/LOD fails, revert source-native KFB clay.

## 4. Three implementation tiers for "a large hole in an original 3D building"
**A. Visual breach / no physical access (cheapest):** apply a source-local UV/object-space hole/damage mask only on a **selected facade submesh / layered skin**, reveal dark interior/card/3DGS and spawn particles. Do NOT claim it is traversable; source mesh collider stays. For shooter POC can be an impactful visual damage outcome, but a player physically passing through would hit invisible wall and fail acceptance.

**B. Cell-proxy breach with real contact (recommended first gameplay Golden):** segment only selected source building **wall region(s)** into a few independently hittable, measured **wall-bay collision proxies**, either by reusing actual GLTF submeshes or attaching a small damage-receiver layer aligned to the source wall. At `DAMAGE_CELL_BROKEN`, hide/remove its corresponding **source facade patch** through mask/stencil/selected separate geometry, turn off corresponding bay collision in authoritative host, keep rest original asset/roof/door/window. Reveal believable inside with dark interior face/rim/damage-edge geometry and a second source card/ball/splat scene, and emit a bounded colored ball stream from the actual damaged boundary into the gutter. For repair restore both visual and collider, once, with supported legal Fluff/Destruct logic. **Key challenge:** if the original building is one closed opaque mesh, the original polygons behind the cut still block the view or player. Need actual source mesh-specific exclusion/masking of *ALL* overlapping faces (including rear/inside polygons) or choose assets with independent front walls/author a small proxy hole corridor. A shader `discard` alone does not yield a physically thick wall aperture; rim/depth thickness must be supplied or preauthored.
**C. True arbitrary mesh/CSG destruction (not required P0):** at import/offline preprocess approved individual hero GLTFs into valid manifold damage patches/variants and collision hulls, preserving UVs/normals/lightmaps and source shape. Prebake hole geometries with incremental transitions. A real-time CSG boolean cut through arbitrary animated or multi-material GLTF on each shot is expensive/fragile, requires robust UV & normal caps, topology cleanup, colliders regenerated, and is **not "simple" because original model exists**. If a hero mesh cannot take B reliably, use A, alternate destructible facade geometry with source-faithful overlay, or a bespoke pre-authored C baked variant.

**Scope/authority:** existing `createDestruct` **donates** cell states, support/repair/debris pooling and shot handling concepts; only current Combat + World/Destruct owner updates accepted gameplay state. The source KayKit GLTF is untouched on disk. The source model remains visually recognizable when intact and partly destroyed; collision and visual aperture match only where access is required.

## 5. Ball spill and scene rules
- A real `HIT_ACCEPTED` → `SHELL_BAY_OPENED` includes `buildingId`, `sourceAssetRef`, `wallBayId`, `localImpact`, `breachNormal`, `integrityBefore/After` and `destructionTick`, validated once by the existing owner. Event **not** inferred from shader brightness or apparent damage.
- Each affected source building can declare one small palette reservoir derived deterministically from a REAL KFB card/artwork's `deckId/cardId` and a bounded bead emission budget. Balls originate from the breach sector, not from a random roof position, and fan out toward free GutterGraph curb+road positions, obey street slope/gravity in a **visual** solver. Most are instanced colored low-poly/clay balls, only a sparse subset contacts the player/curbs.
- Ball artwork colors may inform a Fluff visual. **Do not equate a colorful bead with a real Fluff unit or automatically cleanse Goo**. Only an accepted conversion/collection event changes `cascade-core` route, Goo, Inventory/Save or repair budget. Avoid "every bead one world-damage event" explosions.
- For the *optional* 3DGS interior behind the actual source-asset hole: the hole mask controls splat visibility, while the 3DGS dataset is a separate fixed pocket scene (R14). Avoid assuming 3DGS primitives are physically falling KFB beads or a driveable interior.

## 6. First R16 Golden proof; compare one original asset vs HyperNorm cube
**Small test assets:** one KayKit original building from actual source, one 16:9 Card Cuboid control, one original Joyride curb/walkway segment. Retain original full 3D FB_CANON+Gatling as player, one objective, one real hit and accepted graph/Fluff action. The test uses four equivalent material looks, fixed camera/lighting:
- A original source/native roughness and 3D geometry (must clearly show the KayKit silhouette, windows and original decals);
- B same source with rough-linen woven PBR + stable palette tint, original windows/doors protected; sidewalk separately clay-stone;
- C same source with subtle `terrain3` dynamic bands and optional one accepted HyperNorm window/hero facade, source/cloth details still visible;
- D shot damage to **one** facade bay. Validate source-true visible physical aperture, bay collider no longer active, interior original card or optional 3DGS, single source-color bead spill into actual street, `Goo/Fluff` event + restore/rebuild source geometry and collider.
**Proof views:** exactly same 35° game camera, true eye-height street, roof/flight, close-through-hole with actor, true source material ID/albedo/greyscale and moving weave shimmer test. Verify hit after/before, player cannot phase through intact wall, can pass opened approved wall where intended, no invisible blocked hole, path clearance and Fluff route same as scene, and that when repaired both material/opacity and collision restore. Verify source of all linen texture files.
**QA/perf:** screenshot/record source A→D, one `createDestruct` cell event receipt with unmodified source GLTF, no unintended tint of all sibling cached meshes, mesh intersection and PBR normal maps, actual desktop/mobile p50/p95, material program variants and total texture memory; if mesh-hole B unsupported by current import, use explicit deferred C or support A-only non-traversal and disclose.
**No 56 buildings** until this works and actual limitations are measured.
