## 4. Recommended SINGLE environment composition: three nested reference layers + an overlay
1. **WORLD GROUND** — existing WS1 terrain3 dynamic colorband over continuous real terrain/support. Existing terrain height and collision remain authoritative, plus Diorama-into-ground speckle seam and palette shadows.
2. **URBAN STRUCTURE** — optional bounded actual OSM City Lab footprint/roads/bridge(s) with source geography and true collision. Surface roles road/sidewalk/green/water/building intact. Store `geoOrigin/sourceId/heightProvenance/worldTransform` separately. If not OSM stage, one accepted City Builder authored road maze and semantic graph fulfills same encounter slots.
3. **FUNCTIONAL KIT/DRESSING** — source pinned KayKit City/Prototype/Platformer pieces placed on measured flat/vertical sockets: switch, conveyor, pipe, ramp, interactive facade, roof platform, crate, bakery/restaurant. Existing Dungeon/World Atlas measured-port/Gizmo donor. One compact 2–3 min route puzzle, no full global city.
4. **VISUAL/STATE OVERLAY** — selective R7 source-mask `terrain3-like palette/colorband` on ORIGINAL intended material zone (conveyor threads first, selected platform top later), KFB Clay relief/ink/Goo on targeted attachment, one unified light rig/audio and R5 accepted-fact→soft visual response. Masks are **presentation only**; never rewrite collision, source OSM roads or Fluff graph.

**Important technical seam:** `applyTerrain3` currently paints a full material in world XZ+height and uses `#include <color_fragment>` replacement. Reusing it UNMODIFIED on a single-material KayKit building/blue platform would paint ALL primitive faces, including walls/trim; for a vertical building it may generate stretched/incorrect bands. Use a **small receiver-owned, mask-aware material adapter** that shares palette uniforms and world/host time, but deliberately projects/weights by `materialZoneMask`, source UV or measured local face normal. Never mutate global cached source atlas texture/material; clone per source part. Do not fork a second terrain shader/core.
