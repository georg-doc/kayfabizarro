# Card Dungeon R0 · WSA · 14.11.2026

Standalone opt-in `?dungeon=r0` on the existing owner-private InfiniteRooms Site. No merge or changes to WS1 Stage. Runtime donor: `georg-doc/KFB-Stunt-Car-Race`, `game/integration-r2` at `58b070e6f3c63a444841b5390ea3fac9e337247c`. Site branch: `wsa/card-dungeon-r0-20261114`.

## Play

WASD/arrows move, Shift faster, mouse drag looks, left click shoots at the cursor. Toggle **Heilen** for Cube healing; Slop room remains combat-only. **I** opens an unlocked chest or uses the exit portal. Walk over released cards, dismiss the native Hero-Shot with **Fluffy!**, inspect the native collection fan at top left. `Neuer Prüflauf` creates a new route key without deleting the collection. R0 is explicitly an invulnerable test mode, not balanced survival combat.

Five rooms: two Cubes/chest/1 card → two Cubes/floating/1 → two Slops/chest/2 → one Cube/floating/1 → two Cubes/chest/1. Each room requires resolving all guards and collecting all assigned cards before exit. Twelve-room native generator, five connected main-path rooms. Cards 5–56, deterministic reservations from remaining uncollected cards. Same native world-save, restored guard outcomes and reward receipts; reload resumes the furthest visited room. Original approved Cube eyes/registered K15 EyeGoo used; future WS0 eyes are replaceable.

## Owners and integration seams

Root owns one WebGL renderer, Rapier world, frame loop, camera and movement. SPIEL owns the clock/bus. Module owns progression and thin adapters: native FB A11 graft/LocoActor, npcFigure/flufferSim, combatPlayer.r2, loadout.r1, hostKeys, mobs2d, popupClayCore/TR_AMETHYST, native Türen R5b, cardEdge, cardCollection/worldSave, Hero-Shot, flight and HUDv6 fan. No second loot pipeline or audio context. Healing and Cube damage resolve actual native projectile contacts. Slops use native hit/fall/burst; their `frei` port is bound to room bounds. Camera casts against existing host colliders.

`card-dungeon/create()` accepts injected world and a `shared` owner bundle for host integration. That Stage path is **not tested**; map vendored imports back to the host's canonical modules before integration to preserve the singleton owners. Never ship the vendored closure beside an existing host unchanged. Optional `kfbAudio.preload({bankSets})` port is the only new donor-code proposal; it registers existing admitted audio files in the same bank/context. R2 mindspace patches predate this slice.

All GLBs, purchased popup art, Slop atlases and audio in this checkout remain private. No new external downloads or generated assets. Do not copy this complete checkout into a public repository. Admission/hash receipts are in the WSA shared handoff.
