## One coupled, replayable chain
1. **Card package**: read `registry/assets/v1/decks/<deckId>.json` plus the exact `media/kfb/<actual pdf filename>` (do not guess). Inspect actual image of every printed page where possible. Persist `songs/<deckId>/<deckId>.cards.json` as an array of `cardNumber`, canonical printed normal-case `cardName`, `lore`, `power`, VERIFIED `page` and `imageMotif` per card, `sourceBlobSha`, `mappingVerified`, `visualVerified`. Image motifs MUST come from seen PDF drawings; the legacy JSON `artworkPrompt`, marketing blurb and unverified OCR are not image evidence. If PDF visuals cannot be accessed, set `imageMotif:null`, `visualVerified:false` and say so explicitly; never pretend to have seen them. Pharaoh's old dossier page groups can be a **provisional** mapping with page provenance; not PDF verification. Unreadable card = OPEN, not improvised. Meta/BLANK cards are logged, not invented.
2. **Song lines**: `compose-card-performance` **song mode** consumes the saved cards file and persists `songs/<deckId>/<deckId>.songlines.json` for every numbered card: `cardNumber`, `page`, `cardName`, `source`, `songLine`, `changeReason`, `claim`, `performanceVoice`, `status`. Each card speaks as itself and sells a plausible claim with full conviction, including opposing cards. Base word choice in card name + lore + verified visual motif; POWER only as a brief satirical aside, NEVER an instruction to play/draw/reveal/discard. Log all `songLine` changes; leave canonical cards untouched. No imported claims passing as canon. Spoken R2 triplets are input donors, not binding song copy.
3. **Dossier**: save `songs/<deckId>/<deckId>.dossier.md`: purpose, audience, published printed/sourced identity, four-card printed page → one stanza table, coherent beginning/turn/finale, callbacks, page source evidence, relevant booklet references, and `https://cancelthiscomic.substack.com/archive` as an exploration link; do NOT imply researched Substack articles when unverified.
4. **Writing pass**: combine one four-card printed page into each verse; **exactly one line per included card** and blank line BETWEEN page verses (no same-card duplicates). `[Spoken Word]` must be first, intro with separate lines where spoken pauses matter, an original throughline with sparse varied mini-openers, ending grounded in the deck. Intros are NOT templates, no `Meta-Message`, no repeated opener across earlier song intros, `Uncle FrizzleBob` at most once, `Comic Card Karaoke` only as a fresh optional sing-along idea. Every named card in normal title case (V-271); strict **<5000 Python Unicode characters including newlines**. If cannot fit faithfully, report limitation rather than quietly omit numbered cards.
5. **Styles**: two DIFFERENT danceable musical alternatives; each says genre, production, instruments, groove, BPM, mood and either ONE voice specified by *sonic delivery only* or an explicit duet. Never insert character, storyline, profession, scenes, comic props, or dramatic job names in a style field. Save `<deckId>.style.txt` with `STYLE A` and `STYLE B`.
6. **Independent blind-review handoff**: save `<deckId>.blindreview.md` with exact lyrics, a short source-faithful deck description, and a **reviewer-only payload** from `references/blind-review.md`. The independent reviewer must ONLY see lyrics and that description; it must NOT see these rules, dossier, score targets, comments, or revision history. Obtain three scores 1–10 (song, stand-up, deck faithfulness), three biggest weaknesses, up to eight precise fixes, answers to “Does it sound like a rulebook?” and “Does each card sell its claim?”. A new context of the same agent is **not independently blind by declaration**. If a separate blind reviewer is unavailable, mark `BLIND_REVIEW_PENDING`, no fabricated numeric scores. Prefer independent "KFB Blind Reviewer" GPT supplied only reviewer payload, or WS0's separate agent fallback. Do not create a second plugin automatically.
7. **One revision**: apply at most one reviewer-driven edit round to `<deckId>.wr<N+1>.suno.txt` after *real* review. If review pending, submit `<deckId>.wr<N>.suno.txt` for Georg, mark revision `PENDING_REVIEW`, and do not pass off self-review as blind.
