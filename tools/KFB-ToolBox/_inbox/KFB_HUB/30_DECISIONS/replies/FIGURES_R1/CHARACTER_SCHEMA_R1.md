# kfb.character/1 · one file per character · R1 (WS0, 17.10.2026, V-394)

**One source of truth per character:** `characters/<id>.character.json`. The figure card `figures/<id>.figure.json` (kfb.figure/1) is its **appearance** section and is referenced, never copied. Target location on GitHub per V-394: `characters/<id>/character.json`; this R1 draft sits flat next to the figure cards until Georg says yes.

**Nothing invented.** Every value is merged from an existing sketch. The structural basis is the resident lean card `kfb.resident-lean-card/0.2` (CS-20) plus the `hd-character/v1` fields (CS-40) and the CtP v6.5.2 character block (CS-41). Source IDs `CS-xx` are listed in `CHARACTER_SOURCES.md`.

**Field format (from CS-20):** every leaf is `{ "v": …, "src": "CS-xx §…", "status": … }`. Status: `GEORG` (Georg decision or clarification, register V-xxx), `SOURCE` (found in a file), `DESIGN` (agent-authored proposal inside a source, not approved), `PREFILL` (heuristic fill, needs Georg OK), `todo` (`v: null`, nothing found). Conflicting values stay visible in `conflicts[]`; no silent pick.

**Rules (proposal, binding once accepted)**
1. **Figure card = appearance.** `appearance.figureRef` must resolve; body, eyes, mouth, brows, material are never duplicated here. The figure card's `voice`/`performance` hints are mirrored here; from acceptance on the character file owns them and the figure card refers back (todo for figures R2).
2. **Memory values never live here.** The character file only says *what kind of thing* the character may remember. Player-specific values live in PLAYER_SAVE / NPC_MEMORY_VIEW / JOURNEY_ENTRY (CS-26 §10). Deck content is authored knowledge, not memory (CS-22 §8).
3. **Light is global first.** `lightByStoryMode.table` points to LIGHT_MODEL_R2 B1 (Comic, Heroic, Tragic, Absurd, Mystical, Forbidden). A character only carries an `override` when Georg sets one. L2 rim-light profiles are superseded (V-385/V-392) and are not carried.
4. **Clips by catalog name only.** No clip names outside CS-07/CS-09; Large-rig figures (Orc Brute) use the `(L)` variants.
5. **Canon class is explicit.** Story values from CS-04 keep their class (fixed / proposal / open). DESIGN and PREFILL values never count as canon until Georg says PASS.
6. **Aliases include voice-input mishearings** (V-295), so dialogue and search tools resolve "Hanky", "Anki", "Lori", "Dori" correctly.
