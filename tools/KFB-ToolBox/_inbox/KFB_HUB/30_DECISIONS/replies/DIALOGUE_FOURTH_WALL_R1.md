# Fourth wall in game dialogue: parameters R1 (proposal, not yet briefed) · 17.10.2026

Source: NotebookLM research, Georg's notebook (Google Doc "KFB Modular Storytelling Research", tab "Audio Narrative & Custom Dialogue Manual", §3). Use for the later dialogue slice (WS1, ChatterBox/dialogue scene). Do not start building anything from this yet.

| Rule | Value | Purpose |
|---|---|---|
| Global cooldown between direct addresses to the player | ≥ 45 s | addressing the player stays special |
| Repeating the same line or variant | ≥ 120 s | no parroting |
| Maximum per session | 4 | charm instead of nagging |
| Maximum per turn | 1 | |
| Back-out on fast input (> 3 inputs/s, quick card dragging) | stop the line at once, only short in-world barks | do not slow down a player who is in a hurry |
| Friction (player cancels right after an address) | double the cooldown for the rest of the session | back off when it annoys |

Operators that fit (same document, tab 1): "You played [card]" (FW-01), "You, with the card in your hand" (OP-05), "You said '[word]'" (UP-01), "Agree, or tell me why not" (FW-04).
