## 1 · Micro-storytelling & triplet grammar
The smallest functional unit (beat) must be understandable on its own.

**Minimal grammar:** opener + verified source body + local closure. The parts are joined by CUT, PAUSE, UPTAKE, RHYME or CAUSAL_BRIDGE.

**Beat grammars:**

| Code | Name | Shape |
|---|---|---|
| BG-1 | Expository Assertion | opener → verified source → consequence |
| BG-2 | Rhetorical Counter-Question | question → source-based answer → (consequence) |
| BG-3 | Reframe and Pivot | normal expectation → source detail → unexpected source result / contradiction |
| BG-4 | Deliberate Hesitation | source claim A → source detail B → marked contradiction or silence |
| BG-5 | Audience Remark / Uptake | remark → lexical uptake → character interpretation → source anchor |
| BG-6 | Metaleptic Frame Shift | situation → card mechanism (power) → changed stakes |
| BG-7 | Composite Escalation | visual reveal → short reframe → offer or consequence |
| BG-8 | Modular Null-Bridge | source claim → pause → changed implication |

## 2 · Openers & mini-bridges (response operators)
- **Revelation:**
  - OP-06 "Let me tell you about …"
  - OP-08 "This one has a rule."
  - OP-10 "Nobody warned us about …"
- **Reset / pivot / pause:**
  - OP-20 "Anyway."
  - OP-21 "Before we continue …"
  - OP-23 "Meanwhile, elsewhere …"
  - OP-25 [beat / silence]
- **Uptake / retort:**
  - UP-01 "You said '[word].'"
  - UP-03 "Exactly. And if …, then …"
  - UP-06 "No." + new premise
  - UP-10 "And then it gets worse."
    - Note (WS-Song): this one collides with KayfabeTip 1 ("never and-then"). Use it sparingly and only as escalation.
- **Fourth wall / player sockets:**
  - FW-01 "You played [card]."
  - FW-03 "This card is doing [rule] whether you like it or not."
  - FW-05 "I am performing a card. The card does not care."

## 3 · Fallbacks (failed bridges)
- **CUT:** drop the opener and play the plain card beat.
- **PAUSE:** 200–600 ms of silence.
- **NEUTRAL OPENER:** "Look," / "Still," / "Regardless,".
- **NO_UPTAKE:** the resident states the card beat as an autonomous claim.

## WS-Song note (Georg 20.10.)
The song carrier is the **anecdotal stand-up routine with plausible cartoon causality**: "My neighbor raised a … / So I had to … / Meanwhile …". It follows KayfabeTip 1, therefore/but, but never verbatim and never "and then". The beat grammars and operators are tools for variety within that routine; they are not a template.
