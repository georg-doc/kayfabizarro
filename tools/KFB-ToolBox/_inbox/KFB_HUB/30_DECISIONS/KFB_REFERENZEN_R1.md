# KFB Referenzen R1 · Benchmarks von außen (23.11.2026, V-2100)

Gilt parallel zur SOP (`KFB_SOP_R1.md`, Äste `KFB_SOP_AESTE_R1.md`). Auch hier gilt **Use What Works**. Eine Referenz zählt nur, wenn sie bei uns erkannt, verstanden und umgesetzt wird. Eine schöne Referenz, die niemand trifft, ist weniger wert als eine schräge, die für die Gesamtabsicht wirkt.

**Kein Stil wird kopiert.** In der Zusammenschau beschreiben die Referenzen den eigenen KFB-Stil: Clay-Spielzeugwelt, schiefe Cartoon-Räume, Meta-Absurdität, handgemachte Hintergründe, visceraler Ton.

**Form je Referenz:** wofür (Ast), was genau wir nehmen, was nicht, Golden-Frames (Pfad), Wirksamkeit.
**Wirksamkeit:** `belegt` = es gibt eine Abnahme, die sie trifft. `offen` = noch nicht umgesetzt. `wirkt nicht` = mehrfach verfehlt, Ersatz suchen.
**Frames:** Standbilder oder kurze Ausschnitte aus Georgs Referenzordnern. Vorhandene Sammlungen werden dort verlinkt, wo sie liegen (Dropbox-Pfad), neue unter `75_REFS/<name>/` abgelegt. Der Webchat für Zielbilder bekommt die Frames der passenden Referenz mit. Nur intern als Maßstab, nie im Spiel.

## Pflege
- **Neue Referenz:** Georg nennt sie. WS0 trägt sie mit Ast und „was wir nehmen“ ein und bittet um 3–5 Frames aus Georgs Ordnern. Ohne Frames bleibt sie `offen`.
- **Nach jeder Abnahme:** Trifft ein PASS eine Referenz, wird sie `belegt` und der Beleg dazugeschrieben. Wird sie zweimal verfehlt, wird sie `wirkt nicht`. Dann folgt ein Gespräch mit Georg über Ersatz oder Konkretisierung, statt weiter zu raten.
- **Aufträge nennen die passende Referenz aus dieser Liste**, nicht freie Stilwörter.
