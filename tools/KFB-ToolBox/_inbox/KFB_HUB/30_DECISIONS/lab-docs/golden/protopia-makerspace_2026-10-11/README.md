- **Look der Strecke:** bleibt J17 (V-010/V-102: schieferblaue Fahrbahn, orange Banden). Die hellblaue Fahrbahn mit bunt gestreiftem Randstein im Bild ist nur Stimmung.
- **Biome:** Farm = Protopia bzw. Fluff-Ernte (V-082); Maker Space = Werkstatt- bzw. Bau-Insel (Bezug zu Insel-Editor und God-Mode).
