# KFB Glossar

Begriffe, die in den Quellen dieses Notebooks vorkommen, alphabetisch.

| Begriff | Bedeutung |
| --- | --- |
| **§00 Weltlogik zuerst** | Pflichtfrage vor jedem Element: Wer hat es gebaut oder wachsen lassen, womit, warum, und was erzählt es? |
| **§01 Keine harten Schnitte** | Grundregel für alle Übergänge: organisch, cartoonig, aus Knete, nichts wirkt abgeschnitten |
| **aTW** | Vertex-Attribut mit drei Gewichten (Sand, Pflaster, Fels): wie stark ein Punkt zu einem Material gehört. Der Shader macht daraus Sprenkel |
| **Abschlussstück** | gerundetes Knet-Endstück an jeder freien Kante (Wand, Bord, Bande, Mauer) |
| **Bande (Joyride-Bande)** | roter, gerundeter, cartooniger Straßenrand der Rennstrecken; eine der zwei Randfamilien |
| **Bauweise-Blatt** | Konzeptblatt mit Baugeschichte, Bauteilen und Prüfung je Katalog-Eintrag; Abnahme vor jedem Bau |
| **Biom-Blatt / Biom-Vorlage** | Konzeptblatt je Insel: Geschichte, Arten, Farben, Komposition, abgeleitet aus Deck und Demo-Szene |
| **Blinder Kritiker** | separater Prüflauf ohne Kontext der Bauenden, vergibt Punkte je Kriterium |
| **Claude Design** | KI-Werkzeug für Form- und Look-Entwürfe (Island Kit, HUD, Vorhang) |
| **Clay v10 / Clay K2** | KFB-Knet-Shader mit Relief, Fingerabdrücken und weicher Beleuchtung |
| **Deck** | eines der drei Kartendecks (Utopia, Dystopia, Protopia) mit je 56 Karten; Quelle der Inselgeschichten |
| **Demo-Szenen** | 8 gekaufte StreakByte-Inselszenen (Unity), im Lab nachgebaut; Kompositionsvorlage, nur lokal |
| **Erdung (Etherington)** | wie ein Objekt im Boden sitzt: Eingraben, Kontakt, Überlappen, nach Objektart und Physik |
| **Fluff** | Ressource bzw. Währung der Welt: wächst als Kugeln an Bäumen, wird geerntet, eingesammelt, dient als Bau- und Abriss-Masse |
| **Golden Journey** | kuratierter erster Spielweg mit festen Bewohnern und Szenen |
| **H** | Maßeinheit: Höhe der Medium-Figur = 3,64 Lab-Einheiten |
| **J17 / J14 / J10** | Joyride-Stände (Rennspiel-Donor): J17 Cabrio und Sitz, J14 Straßenmarkierung und `kfbBlend`, J10 Kamera |
| **K2** | Maßstab-Vertrag ohne Meter (H, MC) |
| **kfbBlend** | Shader-Funktion aus Joyride: wählt bei Gewicht w Knetflecken in einem Zellraster, harter Knetrand |
| **kfbLayer** | vier `kfbBlend`-Aufrufe mit verschiedenen Zellgrößen: große Flecken, mittlere und kleine Tropfen, Rücktropfen. Das ergibt das Sprenkelbild |
| **Knetstein / Mauerwerk-Familie A** | gemeinsame cartoonige Steinfamilie für Bord, Mauer, Treppe, Plateau, Brücke, Pyramide |
| **Lab** | KFB Island Worldbuilder Lab: lokaler Editor und Viewer (Vite, three.js r186) |
| **MacroCell (MC)** | Maßeinheit: 4 KayKit-Einheiten = 6,4 Lab = ein Dungeon-Modul = ein Stockwerk |
| **Open Stage / freistehender Raum** | halb offene Raumszene mit Teilwänden, Abschlussstücken und Rubbel (Ruinen-Logik) |
| **PASS / TUNE / FAIL** | Georgs Abnahme-Urteile: bestanden, nachbessern, verworfen |
| **R2D v0 / R2B** | Claude-Design-Inselstände, die als Qualitätsmaßstab gelten |
| **RACE_W** | Faktor 1,46 für Rennprofile auf Inseln, damit Weltautos überall fahren |
| **Residents** | Bewohner mit eigenem Leben, Activities und Stimme |
| **RKIT** | Racetrack Construction Kit (R3): Straßenbaukasten aus Track Core und Blender |
| **Road-Bed (`kfb.road-bed/1`)** | Datenformat der Naht Straße ↔ Gelände: Maske, Naht, Freiflächen, Anker, Rand |
| **Rubbel** | Knetkrümel und Knetsteinchen an Nähten, Kanten und Füßen; erzählt Bauen, Abtragen, Verfall |
| **Schürze** | Teil des Straßenkörpers, der mindestens 0,3 unter das Gelände taucht, damit kein Spalt sichtbar ist |
| **Scholle v7** | Inselunterseite: schwebende Erd- und Felsscholle mit zentraler Spitze und senkrechten Ausläufern |
| **Sprenkel** | Übergangsart mit Punkt- bzw. Fleckenmuster (kfbLayer), Standard für Erde, Sand, Pflaster, Fels |
| **SSOT** | Single Source of Truth, hier GitHub `georg-doc/kayfabizarro` plus Lab-Dokumente |
| **Track Core** | Straßen-Compiler: Profile (Querschnitte), Stationen, Familien, Prüfungen |
| **Viertelkreis-Kante** | Rundung der Inseloberseite über den Rand in den Fels |
| **Worldbuilder-Modus** | Editor, in dem Georg selbst Inseln formt und Objekte setzt |
| **Zackenkappe** | Schnee-Übergang mit gerundeten Knetzungen bergab, harter Knetrand, keine Linie |
