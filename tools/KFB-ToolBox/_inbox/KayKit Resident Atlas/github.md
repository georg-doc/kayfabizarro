## Notes

- Model binaries (.glb/.gltf) do not appear in the CONNECTOR's github_get_tree listing (it filters to importable files), but the GitHub tree API returns them in full — that is how the Orc Brute and Monstrosity paths were proven in S24. Registry shards and the handoff JSON remain the richer source (they carry rig facts and dependency status); a tree walk proves existence only.
- `registry/assets/v1/packs/kaykit-mystery-series6.json` (916 assets) is too large for the connector copy; evaluate it over the raw URL when the rest of the cast is needed.

- Asset Registry stays the source of truth; this project is a read-only consumer.
- `_inbox/KayKit_PACKS_References_Scenes_Demos/*.gif` in georg-doc/KFB-Stunt-Car-Race is >5 MB and cannot be pulled through the connector; reference images come from the local `reference` folder / uploads instead. The two Patreon recap GIFs now in `ref/atlas/` came that way.
- The `*_Large` weapon/shield variants are the Rig_Large size class, not decorative alternates — verified as exactly 2× on six pairs and against three promos. Any new Large-tier resident equips the `*_Large` file; a Medium-pack prop on a Large rig needs `s: 2`.
- KayKit ships variants and accessories as SIBLING MESHES inside one file, not as separate files — `ActionFigure.glb` carries its own head, a cigar and a headband; each head file carries shell, face plane, cigar and headband. A variant swap is therefore a visibility question (`hide`), and a fitted part must switch off whatever the base already brings. Expect the same shape in any future KayKit pack with variants.
- Face expressions on the Action Figure are an atlas coordinate, not geometry: a 2×2 sheet of 512² tiles, one per expression, each head sampling one. Read the native tile from the mesh's UVs; clone material AND texture before offsetting.
- A prop's PIVOT tells you which hand it belongs to before any measurement: a pivot in the neck top of a guitar means the grip hand, not the strum hand. Getting that wrong cannot be fixed by tuning the aim vector — S26 spent a full roll sweep on a pose that was on the wrong arm.
- `KayKit_Mixed_Bag_1_FREE` IS fully usable (41 glTF files). Do not re-derive pack emptiness from `github_get_tree` — it hides `.gltf`/`.bin`. Use `github_search_code` for `Khronos glTF Blender` scoped to the pack prefix.
