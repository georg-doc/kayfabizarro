Paper/Dark-Grammatik

Kompakter Heute-Fluss
20-px-Wortmarke „KFB Hub“, kleine Links, KFB/DocCheck-Fokus, Suche + Filterleiste. Start ist #today: Heute-Raster zweispaltig, 12-px-Titel, eine Zeile Text, Abhaken lokal.
Pocket Inbox / Dropzone
Offenes details, einzeiliges Notizfeld + gestrichelte Dropzone (.md .txt .json .zip), Speichern / Exportieren / Leeren, Zähler. IndexedDB kfb-hub-pocket-inbox-v1, Status „Lokal · kein Upload“.
Suche und Filter
Freitext über Titel, Bereich, Tags. Taste / fokussiert, Esc leert. Filter sind Hash-Routen: Heute, Briefings, To-dos, Stage/Live, Tools, Projekte, Recovery, Town, Regeln, Historie, Alles.
Progressive Disclosure
Heute zeigt nur Aufgaben, Briefings und Inbox. Historie, Regeln und Linklisten erscheinen erst über den Filter. Beschreibungen auf 1–2 Zeilen gekürzt.
ToolBox-Prominenz
„ToolBox“ als fester Link in der Kopfzeile, ToolBox-v2-Router als erstes Briefing. WorldBuilder hat im Donor noch keinen Kopfzeilen-Platz; das ergänzt der Kandidat.
