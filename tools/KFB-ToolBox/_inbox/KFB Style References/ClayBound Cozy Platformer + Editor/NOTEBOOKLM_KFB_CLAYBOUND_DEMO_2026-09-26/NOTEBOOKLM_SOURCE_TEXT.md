# KFB × CLAYBOUND
## 3D Character Design Production Deck · NotebookLM Demo Source

### PURPOSE

Create a **15-slide visual 3D character design production deck** using the supplied KFB character references and ClayBound screenshots.

This is an experimental visual-development task.

The goal is to explore how the existing KFB 3D characters could be translated into a **handcrafted clay / claymation design language** while preserving their original identity.

The ClayBound screenshots are the primary STYLE reference.

The KFB model references are the primary CHARACTER reference.

Do not redesign the KFB characters into unrelated cute characters.

---

# CORE DESIGN PRINCIPLE

The desired result should feel as if the existing KFB character had been physically sculpted and art-directed in clay.

Preserve:

- recognizable silhouette
- proportions
- face construction
- characteristic features
- color relationships
- costume and prop identity where visible
- personality

Translate:

- geometry
- material response
- surface character
- edge treatment
- small asymmetries
- pose presentation

into a handcrafted claymation language.

---

# CLAYBOUND VISUAL LANGUAGE

Study the supplied ClayBound screenshots carefully.

Derive the visual principles from the actual references rather than applying a generic “clay filter.”

Desired characteristics include:

- rounded sculpted volumes
- soft transitions
- slightly imperfect handmade geometry
- matte surfaces
- subtle material variation
- restrained microstructure
- tactile but clean presentation
- soft studio-like lighting
- clear silhouettes
- strong color blocking
- readable character design

Avoid:

- fake fingerprint overlays
- obvious procedural noise
- repetitive bump patterns
- glossy plastic toy rendering
- photoreal dirt
- random scratches
- generic Pixar-like redesign
- generic mobile-game character styling
- exaggerated cute proportions unless already present in the source character
- visual clutter

Handmade does not mean dirty.

Clay does not mean covering every surface with fingerprints.

# 15-SLIDE DECK

## SLIDE 01 — CHARACTER HERO

Present the strongest overall claymation interpretation of the KFB character.

Large hero image.

Minimal supporting text.

Show the intended final visual target.

---

## SLIDE 02 — SOURCE CHARACTER DNA

Show the supplied original KFB model references.

Identify the visual features that must remain recognizable.

Focus on silhouette, proportions, face, colors and distinctive details.

Do not improve or redesign the source character on this slide.

---

## SLIDE 03 — KFB → CLAY TRANSLATION

Show a visual comparison between the source design and the clay interpretation.

Explain what changes and what remains invariant.

The result must still clearly be the same KFB character.

---

## SLIDE 04 — SHAPE LANGUAGE

Break the character into major sculpted forms.

Show:

- primary volumes
- secondary volumes
- rounded transitions
- controlled asymmetry
- characteristic silhouette

Treat this like a professional character-design shape study.

---

## SLIDE 05 — HEAD & FACE

Create a focused facial construction page.

Study:

- eyes
- eyelids
- brows if present
- mouth
- cheeks
- nose
- ears
- characteristic facial geometry

Show close-ups and small construction studies.

Preserve character identity above stylistic novelty.

---

## SLIDE 06 — EXPRESSION RANGE

Create a compact expression sheet.

Approximately 6–9 useful expressions.

Favor readable acting suitable for presentation and explanation:

- neutral
- curious
- explaining
- skeptical
- pleased
- surprised
- concerned
- thinking

Avoid emoji-like exaggeration.

---

## SLIDE 07 — BODY & POSE LANGUAGE

Create a pose sheet for the character.

Include useful production poses such as:

- neutral / idle
- explaining
- pointing
- presenting
- thinking
- reacting
- walking or moving

If animation references are supplied, use their actual motion language as inspiration.

---

## SLIDE 08 — CLAY MATERIAL SYSTEM

Define the character's main surface system.

Show large material samples and close-ups.

The hero clay surface should be:

- matte
- tactile
- softly irregular
- non-repetitive
- visually quiet enough for animation
- compatible with soft lighting

Use subtle variation rather than obvious texture effects.

---

## SLIDE 09 — SEAMLESS CLAY TEXTURES

Create a small library of **seamless / tileable clay textures**.

Examples:

- smooth matte clay
- fine-grain clay
- lightly worked clay
- compressed / rolled clay
- slightly porous clay

Show each texture as a clean square material swatch.

The texture must behave like a production texture, not like an illustration of a clay object.

Requirements:

- seamless horizontally
- seamless vertically
- no frame
- no central object
- no directional lighting gradient
- no obvious repeating motif
- no fake fingerprint pattern
- subtle enough to use on an animated 3D model

For every swatch provide a short image-generation prompt suitable for recreating the texture.

---

## SLIDE 10 — SECONDARY SEAMLESS MATERIALS

If appropriate for the supplied character, create additional seamless materials such as:

- felt
- woven textile
- soft rubber
- paper
- cardboard
- cork
- matte painted surface

Only include materials that make sense for the actual character.

Do not create a decorative texture catalogue for its own sake.

---

## SLIDE 11 — TEXTURE PRODUCTION SHEET

Turn the strongest texture concepts into a concise production board.

For each texture specify:

- name
- intended material
- intended character area
- relative visual scale
- roughness character
- surface intensity
- tiling behavior
- what to avoid
- ready-to-use texture-generation prompt

Prefer approximately 6–8 useful textures rather than dozens of variants.

---

## SLIDE 12 — MATERIAL ZONE MAP

Show where the material families belong on the character.

Use a character view with clear visual annotations.

Differentiate:

- primary clay body areas
- face
- clothing
- accessories
- props
- special materials

Keep the number of materials controlled.

---

## SLIDE 13 — CLAYMATION / MOTION BEHAVIOR

Show how the clay character should behave in motion.

Explore subtle handcrafted qualities such as:

- tiny pose-to-pose variation
- soft compression
- restrained squash and stretch
- slight sculptural irregularity between poses

Avoid constant wobbling.

Avoid texture swimming.

Avoid treating stop-motion as an automatic low-frame-rate gimmick.

The character still needs clean readable acting.

---

## SLIDE 14 — KFB APPLICATION

Create several mini examples showing how this clay character can function inside an illustrated KFB slide deck or visual explainer.

Examples:

- presenting a concept
- pointing toward a diagram
- observing a process
- interacting with a label or object
- reacting to a fact or event

The character supports the information.

The character should not consume the entire information hierarchy.

---

## SLIDE 15 — FINAL PRODUCTION BOARD

Summarize the proposed visual system.

Show together:

- final hero character
- main expression
- representative pose
- core clay material
- strongest seamless textures
- color palette
- small KFB application example

This should function as a compact visual handoff for further 3D production.

---

# SEAMLESS TEXTURE GENERATION RULE

When creating or proposing texture images, treat them as genuine **3D material inputs**.

A texture prompt should describe the physical surface itself.

Good direction:

“Seamless tileable matte modeling clay surface, extremely subtle organic microvariation, softly compressed handcrafted material, uniform neutral illumination, orthographic material sample, no object, no border, no directional shadow, production texture, seamless x/y.”

Bad direction:

“A cute lump of clay with fingerprints on a table.”

Textures must be usable as surfaces.

Not illustrations of surfaces.

---

# VISUAL PRIORITY

The hierarchy for all decisions is:

1. preserve the supplied KFB character identity
2. follow the supplied ClayBound visual references
3. maintain a coherent handcrafted material system
4. support animation and presentation
5. add novelty only when it serves the design

Do not introduce a different visual franchise.

Do not introduce unrelated branding.

Do not invent UI chrome.

Do not convert the character into a generic AI-generated mascot.

The final deck should look like a professional **3D character visual-development and material-production board**.
