HUD je Reisemodus

Gestrichelt: Figurzone, bleibt frei.
Gehen
Fluff-Score, Kompass bzw. Inselname dezent; kein Tacho. Ruhig, fast leer.
Fahren
Tacho als Knet-Rundinstrument, Radio mit diegetischen Knöpfen (Musik an/aus, Zurück, Play, Weiter, Playlist), Fluff-Score. Armaturenbrett-Teile aus Knete.
Fliegen
Luft-Tacho, Höhensäule, Schub-Tank (Düsenflamme = Schub, fünf Tropfen = Energie), Fluff-Score; das Radio bleibt und rückt zusammen.
Mobil · Fliegen
REGELN
Ecken und unterer Rand, nie über der Figur. Oben rechts steht immer der Fluff-Zähler, unten links das Fahrzeug- bzw. Jetpack-Instrument, unten rechts das Radio.
Unter 1180 px schrumpft das HUD bis auf 62 %. Unter 620 px Breite, oder wenn es unten eng würde, rückt das Radio ohne Display in die obere Reihe neben den Rucksack. Oben bleibt es eine Zeile, unten hat die Figur Platz.
Jedes Teil ist ein Gegenstand: Plakette mit Sockelschatten, dunkle Mulde, Pfirsich-Knöpfe drücken sich 2 px in den Sockel. Jedes Teil hat eine feste, leichte Neigung.
RADIO · ZUSTÄNDE
Musik aus
Nur der Noten-Knopf. Antippen schaltet ein und klappt auf.
Fahren · an
Display mit Titel und Künstler, dazu Zurück, Play, Weiter, Playlist.
Fliegen · kompakt
Kürzeres Display, damit unten Platz für die Jetpack-Instrumente bleibt.
Mobil · ohne Display
Nur die Knöpfe; der Titel steht im Playlist-Menü.
Playlist-Menü
Biom-Radio plus alle Kassetten aus dem Rucksack. Die laufende Playlist ist markiert.

Flug-VFX

Jeder Effekt ist ein eigenes Modul und einzeln schaltbar. Feste Pools, fünf bis sechs Draw-Calls.
Speedlines
Zwei Bänder an den Außenkanten von Jetpack oder Kart. Sie hängen am Träger, laufen dünn aus und folgen Bank und Rolle ohne Abriss. Unter 18 km/h ziehen sie sich ein.

Manöver-Linien

Jetpack-Schub
Drei angeheftete Kern-Wülste je Düse, darunter Tropfen, die sich lösen, abkühlen und mit Knetfleck-Rand zerfallen.

API
import { createHud } from './kfb-hud.js';
import { createFlightVfx, createSpeedTrails, hoverPose } from './kfb-flight-vfx.js';
import { createPropLibrary, createPropRenderer, mountBackpackMini, createBagOverlay } from './kfb-backpack.js';
import { BIOMES, BIOME_STATIONS, TRACKS, TAPES, ITEMS } from './kfb-jukebox-data.js';

const hud = createHud({ mode: 'walk', palette, host });
hud.setSpeed(kmh)  hud.setAltitude(m)
hud.setThrust(0..1)  hud.setEnergy(0..1)
hud.setFluff(n)  hud.addFluff(k, { from: { x, y } })
hud.setMode('walk' | 'drive' | 'fly')
createHud({ palette: BIOMES.dystopia.hud })
hud.radio.on('music' | 'play' | 'prev' | 'next' | 'playlist', fn)
hud.radio.setPlaylists([{ id, label, sub }], activeId)
hud.radio.setTrack({ title, artist, index, count })
hud.radio.setMusic(b)  hud.radio.setPlaying(b)
hud.backpack.onOpen(fn)  hud.backpack.setCount(n, 20)

const bag = createBagOverlay({ host, palette: hud.palette, lib, view, items });
bag.on('insertTape' | 'ownSong' | 'use' | 'eject', fn)

const vfx = createFlightVfx({ scene, camera, body,
  nozzles: [{ object: jetpack, offset, dir }],
  trails:  [{ object: jetpack, offset }],  // Außenkanten
  surfaceAt: (x, z) => ({ y, water }) });
vfx.update(dt, speedKmh, thrust)
vfx.maneuver(1, 0.9)               // Manöver-Linien
vfx.setTrailAnchors(kartCorners)   // Wechsel auf Kart
vfx.setSkim(false)                 // Überflug aus
vfx.setGrounded(bool, groundPos)   // löst Puff aus
hoverPose(t) → { y, pitch, roll, leg }
createSpeedTrails(...)             // auch fürs Racing
vfx.dispose()
palette nimmt ein Teilobjekt von HUD_THEME_V1 oder nur { primary, accent }; die übrigen Töne werden gemischt. Damit lässt sich das HUD an ENV_ROLES hängen.
ÜBERNOMMEN
Plaketten-Look aus hud-theme.v1 (Open-World-Styleguide): Lila-Plakette, dunkle Mulde, Pfirsich-Knopf, Knet-Korn, unregelmäßige Radien, Neigung.
Anordnung aus dem Racer-HUD v2: Tacho unten links, Radio als Leiste, Mitte frei.
Speedlines: Bandaufbau 1:1 aus TinySkies Contrails.ts über contrails.js (Travel Globe v13): 72 Punkte, Querachse zur Kamera, Breite × fade, Alpha × fade², additiv. Dazu aus v13 Anker im Träger, Mindestschritt, Einzug, kein Tiefentest.
Manöver-Linien: Spindel-Shader und Ring-Logik aus speed-lines.js (Travel Combat v25, Port von TinySkies SpeedLines.ts).
Überflug: Emission unter dem Fahrzeug in zwei Fahnen, Alpha (1−t)², Projektionsfaktor mit Pixeldeckel aus carpet-wake.js (Travel Globe v13, Port von TinySkies CarpetWake.ts).
Flug-Start per Doppel-Leertaste wie in sw-mech.js (Seed World).
Rucksack-Regeln aus Golden Journey Beat 4: 20 Fächer, Taxi-Schlüssel als Pflicht-Item, KayKit-Rucksack (Hoarder gewählt, Orc als zweiter Kandidat). Karten bleiben im Almanach.
Modelle: Hoarder_Backpack (KayKit Mystery S6), key (KayKit Dungeon 1.1), donut_pink (Tiny Treats Baked Goods), radio (Tiny Treats Pleasant Picnic), map_rolled (KayKit RPG Tools), live aus dem Repo, Commit f8f8f1fd.
Biom-Farben vom Referenzblatt 01-farbpaletten (Hex-Inseln, hex-archipel.r2c.js). Titel aus disco-playlist-01 (Rotation 01, gemessene BPM) und jukebox.json.
NEU GEBAUT
HUD-Teile: Höhensäule, Schub-Tank, Fluff-Zähler mit Flugkugel, Kompass-Plakette, Roll-, Plopp- und Steig-Wechsel.
Speedlines: warmes Creme statt Eisblau, Anker an den Tank-Außenkanten bzw. hinteren Kart-Ecken, Maße für eine 1,7-m-Figur.
Manöver-Linien: Auslöser mit Hüllkurve statt Dauerbetrieb, additiv hell, verbeulter Rand, Figurzone frei.
Überflug: flache Welt statt Globus, Höhen-Tor, Knet-Staub mit dunklerem Rand über Boden, Gischt über Wasser.
Schweben: hoverPose(t) und Minimalschub 0,14.
Rucksack: wippende Miniatur, Overlay klappt aus dem Slot auf, 5 × 4 Knet-Mulden, Kassettendeck im Radio-Item. Ein WebGL-Kontext für alle kleinen Ansichten.
Radio R3: Noten-Knopf als Musik an/aus (aus = minifiziert), Zurück/Play/Weiter, Playlist-Menü statt Quellen- und Lautstärkeknopf, Pixel-Lauftext (VT323). Mobil ohne Display in der oberen Reihe.
Jetpack-Schub, Puff: Knet-Wülste, Tropfen, Rubbel-Ring und Krümel aus einer verbeulten Kugel; Zerfall über Rauschschwelle mit dunklem Rand.
Kassetten sind Knet-Platzhalter: In KayKit und Tiny Treats habe ich kein Tape-Modell gefunden.
Annäherung, nicht gelesen: Clay-SSOT (KFB_CLAYMATION_STYLE_SSOT.md, PR #301) für den Knet-Look der Items, kfbBlend, Clay K2/v10, Rubbel-Grammatik, ENV_ROLES. Der Knetfleck-Rand ist nachempfunden. Comic-Contrails aus Travel Globe v13 sind nicht portiert.
