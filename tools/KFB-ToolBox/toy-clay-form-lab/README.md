# KFB Toy / Clay Form Lab v0

Status: EXPERIMENTAL DONOR / ToolBox authoring lab.

Purpose: reusable geometry grammar for chunky, rounded KFB props and landmark icons without replacing Tiny Treats, KayKit, Asset Librarian, City Grotesque or img2threejs ownership.

The Stage viewer starts with the real Tiny Treats Charming Kitchen toaster isolated. Only then may the procedural samples be reviewed:
1. rounded three-button panel;
2. Eiffel toy landmark;
3. Cologne Cathedral toy landmark.

Reusable code:
- lib/kfb-toy-primitives.mjs
- lib/samples.mjs

Technical language: visible macro bevels, capsule beams, smooth lathed spires, matte toy/clay materials, hard part budgets, silhouette before micro-detail.

This donor does not become the Landmark default automatically.
