# KFB Eye Actor Studio v0

Status: EXPERIMENTAL TOOLBOX CANDIDATE.

Motto: **Eye — including lids and brows — as actors.**

This studio extends the existing ToolBox eye-authoring line without replacing EyeRig v6, BrowRig v2 or Batch EyeRig.

EAS-0 proves:
- exact EyeRig v6 donor mode on a neutral synthetic FaceHost;
- optional volumetric Clay-Lid adapter with four independently controlled lid meshes;
- BrowRig v2 as a volumetric expressive companion;
- candidate pose library for skeptical blink, aim, tired, angry and surprise;
- face > body > main color-resolution contract;
- less overbright sclera/pupil shading preview;
- under-eye shadow preview;
- eyeFrame-anchored 3D emanata: sweat drop and soot dots;
- desktop/mobile authoring surface.

Deferred:
- real actor batch import from current EyeRig Batch profiles;
- Legacy/vehicle/prop/plant host adapters;
- final eye-ring shader;
- modelled heart/spiral pupil FX;
- consumer animation triggers and gameplay ownership.

The current EyeRig v6 source remains canonical 3D donor.
