# Claude Design Start Here · KFB Clouds 01

## Goal

Design **three KFB cloud construction families** using the attached reference pack.

This is not an artist-style imitation task. Extract construction logic from the references, then translate it into KFB's own clay/cartoon language.

## Read

1. `PACK.json`
2. Open each reference marked as required in its **original source URL**.
3. Inspect the actual source object before making design claims.

## Mandatory first pass

Before designing, return a compact source-isolation note for each reference:

- reference ID;
- source URL opened;
- what is visibly observed;
- what remains uncertain.

Do not substitute Google/Pinterest images.

## Design questions

For the primary Clouds reference:
- How are major cloud masses grouped?
- How is the outer silhouette prevented from becoming repetitive?
- Where do secondary/tertiary forms appear?
- How do overlaps imply depth?
- What makes the cloud readable at small scale?

Use Smoke only for transferable volume/layering logic.
Use Spacing in Composition only for grouping/negative-space logic.

## KFB translation

Produce three clearly different cloud families suitable for later 2D/3D/procedural use.

Each family should define:
- dominant mass count/range;
- secondary lobe ratio;
- overlap rule;
- silhouette irregularity;
- vertical compression/elongation;
- spacing rule;
- underside/topside distinction;
- optional clay deformation/noise;
- what to avoid.

Keep forms simple enough to become procedural assets later.

## Output

Return:
1. source-isolation evidence;
2. three cloud families;
3. concise construction grammar for each;
4. which exact reference IDs informed each rule;
5. one recommended family for first KFB procedural/3D proof;
6. unresolved questions.

Do not create a new asset owner or runtime.
