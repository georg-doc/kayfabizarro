## C · Exactly one consumer journey / interface
Existing Librarian inspector and Town Scene Plan get a non-invasive action **Create KFB Image** (no new nav chrome/second home page); accepts one selected `assetId`, or the existing `kfb.town-scene-candidate.v1` packet. Action opens a small preflight panel: mode `Source-locked asset plate` (default on 3D asset), `Scene context` (default on existing scene packet), `Material only`, `Mood exploration` (explicit, weaker form lock). It previews **actual** isolated source image and explains source/permission status; user may choose light/moderate KFB clay profile but no blanket clay deformation. One click **Create** queues a durable job and shows in-place progress; no fictitious immediate PNG. Completion shows result, donor compare, parts, provenance, download and `TUNE / REJECT / ACCEPT AS STYLE` review. Explicit `Golden` needs Georg's named choice.

**No form-heavy UX.** Context is passed automatically from the existing clicked asset/scene; preserve current search/filter/preview selection, source pinned/latest mode and URLs. No replacement KFB branding or invented badges.
