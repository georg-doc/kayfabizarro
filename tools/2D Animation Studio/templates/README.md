# 2D Animation Studio · Rig Templates

Templates are topology/contract donors, **not visual SSOTs**.

Current first reusable topology:

- `DOCCY_QUADRUPED_RIG_TEMPLATE.v0.1.json`

It generalizes the Eumel source-first cutout method to a quadruped:

- source ingestion first;
- neutral bind from measured geometry;
- explicit shoulder/hip anchors;
- optional restrained bend/stretch/squash;
- shared EyeRig protocol;
- local presentation only.

A template never authorizes generating or redrawing a character from prose.
