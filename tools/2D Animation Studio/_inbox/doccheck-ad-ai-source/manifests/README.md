# Manifests

This folder will receive machine/human-readable intake results, for example:

- source file identity + checksum/revision;
- artboard/layer/group inventory;
- reusable asset inventory;
- eye/pupil rig map;
- pivot/anchor map;
- outline-family measurements;
- export compatibility notes;
- promotion decision.

Do not fabricate missing source structure. Record unknowns explicitly.
