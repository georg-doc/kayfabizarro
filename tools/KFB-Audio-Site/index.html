Current audio rules

CatalogOne canonical Jukebox. All authored songs stay. Catalog membership is not player unlock state.
MastersComplete master recordings are Ground Truth and style references.
Music statesB = movement/adventure, C = staying/cozy exploration, D = talking/social interaction. They are smooth mix targets, not hard track switches.
TTS duckingVoice focus remains a separate existing mixer concern. D adds speech-space bias; it never replaces ducking or pauses the music timeline.
StemsSource-only unless individually listening-certified. New B/C/D slots are metadata-ready but intentionally contain no placeholder audio.
World seamA later World adapter may emit movement, staying, dialogue, POI and Billboard context. The existing audio owner resolves the state and transition.
MemoryLean Memory stores track receipts: track id + resident/biome/event/seed. Fractal Almanac reconstructs the music memory without copying audio.
Missing bankRain, thunder, sustained crowd, traffic and proper tyre/friction sources remain explicit acquisition work.
This Site is the existing catalog/authoring owner. Consumer games keep their own gameplay truth and feed context through the adapter seam.
