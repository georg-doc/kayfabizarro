# HUD_SKIN_SPEC · KFB Clay UI Skin Authoring R1
Status: shared authoring design contract · 2026-11-04 · WS0 / KFB ToolBox. No new runtime.
## 1 · Kartenkante: skin signature versus code primitive
Only paint distinct SKIN SIGNATURES: theme head/terminal/end, decorative six Fluff ring collars, a 4-slot vertical radio signature shell, distinct themed emblems/glyphs, pipes/coils/LEDs/antennae/drips. Existing code recolors/re-surfaces all generic panels, settings boards, sliders, toggles, tabs, plaques, tiles, close/X and neutral buttons. Never redraw a generic rounded rectangle for every skin. Counts, typography, values, map route, telemetry, action availability and song state are always code and current owner truth.
One reusable HUD layout contract, many skin manifests. It does NOT mean a second HUD runtime; World/Travel/Race existing components continue to own behaviors.
## 2 · Graphical controls
Rounded accurate silhouettes, clean even frame thickness, controlled plasticine fingerprints and matte tonal variation rather than wobbly outlines, random lumps, cracks or visible repeated texture tiles. Soft upper-left light; no baked shadow, text, labels, background/checkerboard or faux branded chrome on exported sheets. True PNG RGBA with zero-alpha background. Every element entirely isolated with at least 32 px clear gap; no antialias/halo cut. Readable at 48/64 px; don't rasterize numbers into Fluff balls or speed bars.
Preserve exact visually inspected source identity. Source loaded is not visual acceptance. Exclude failed cropped pieces from new style prompts.
## 3 · Canonical roles / skins
- Fluff bar CLOSED = themed left head + SIX empty round slots + one empty wide numeric field + right cap. OPEN = same + content drawer + small arrow. Code owns actual six colors/counts and empty=grey.
- Radio at right edge = fixed narrow vertical control head, FOUR empty square slots stacked, three small lamp indicators, optional thematic grille or electrical face. Maxified = independent large panel that slides LEFT; must not repeat the minified radio frame. Audio state and playlist from existing audio owner.
- Actions = configurable 1–6 sockets in the shared kit; receiving Race HUD currently renders FOUR anchored roles (primary, secondary, movement, context only when available). The existing inventory, cooldown and weapon/throwable selection remain owned by receiving game.
- Minimap, target/compass, navigation pointer = theme-specific optional bezels/glyphs; map and waypoint from existing map/gameplay owners. Not auto-added to Race WS0 October layout.
- Right-edge tempo/flight = narrow travel strip for speed, optional altitude, jetpack/fuel/boost; visual terminal may be signature art, the numeric scale/units/camera and vehicle telemetry belong to Race/Travel/World. Do not duplicate telemetry.
- Inventory/backpack (5x4), Almanac fan, quote card, speech bubble, narrator, settings and caption overlays = use existing owner and code-primitives; paint only distinguishing emblems.
- States: NORMAL, HOVER, PRESSED, ACTIVE, DISABLED, LOCKED, COOLDOWN, HIDDEN. Code overlays/recolors common states; distinct image for a signature pressed glyph only when necessary.
## 4 · Dynamic panel contract
Keep radio bar and drawer separate cropped RGBA images, each outline complete; no shared hinge/remnant. 3-slice for height only, 9-slice for height+width. Lock corners and distinctive screws, vents, warning stripes, luminescent tubes, slime drips and brackets in separate overlays. Stretch only plain straight edges; plain texture or shader fills center without repeated visible stamp. Insets are measured per skin and saved as manifest JSON. No fixed universal cut coordinates.
Visual acceptance: isolate donor; inspect minified and drawer separately on dark/light; render source-scale and 300x500, 440x650, 600x900; inspect seams and 48/64 px readability; compare expanded and collapsed in the receiving game's actual anchor positions. Reject cropped or twice-distorted details.

Check native image dimensions 2048x2048, RGBA true alpha with fully transparent background, separation/cell padding 32px, all specified motifs, no overlapping or cropped decorations, constant edge geometry for slicing and visual donor match. File format/alpha alone cannot prove content or skin quality.
