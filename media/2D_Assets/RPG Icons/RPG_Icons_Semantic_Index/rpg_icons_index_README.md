# RPG Icons — Semantic Index

400 original 32×32 PNG icons, indexed without altering the source artwork.

## Taxonomy

- **weapon** — Combat weapons: swords, maces, polearms, miscellaneous weapons, bows and crossbows.
- **armor** — Wearable defensive gear: shields, helmets, chest armor, gauntlets and boots.
- **equipment** — Accessories and emblems: rings, amulets and rune/emblem badges.
- **item** — General inventory items: herbs, ingredients, containers, tools, books and chests.
- **consumable** — Alchemy/consumable potion family.
- **resource** — Gems and stones, grouped by color family and shape variant.

## Naming principle

Names are intentionally conservative: they describe what is visually clear at 32×32 rather than inventing lore or exact item mechanics. `filename` remains the canonical link to the original PNG.

## ID convention

`rpg_0001` → `Icon1.png`, etc.
