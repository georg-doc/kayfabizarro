## Inspect before delivery
Inspect original pixels and a 160–192px view, not just a success message. Check distinctive geometry, supports, coherent anatomy, correct lettering, full framing, material-specific contour, pattern scale transitions and distant readability. Technical checks: alpha channel, dimensions, hashes and bytes. Alpha extrema 0/255 alone do not prove clean extraction; inspect holes and fringe. A palette gate must use an actual named palette and documented tolerance, otherwise mark palette unverified. Never claim a mathematical image topology or WFC computation from a prompt.
Do one narrowly targeted repair for a concrete flaw. Two non-improving repairs on one seam: retain the attempts, name the failure and change strategy rather than endlessly iterate. Dice/impossible geometry need verified form guides first; organ anatomy benefits from a real source model/reference. Do not make the user micromanage repeated regressions.
