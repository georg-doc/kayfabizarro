1. **WS0/WSA intake:** get actual source PNG bytes from approved ChatGPT Webchat ZIP (not preview screenshots or ephemeral links); verify the SOURCE_INTAKE hashes. User selects private/public intake route. Display a true isolated source donor before choosing atlas cells.
2. **Visual/crop gate:** six L0 Normie candidates from one sheet, no original redesign. Fix only demonstrable alpha/cell bleed; preserve approved identities. Record six stable source IDs and final sprite SHA; reviewer examines 96px, full res, dark/bright background.
3. **Asset registration:** submit real files into existing KFB source/private-asset intake, run the existing registry build/validation and confirm read-only Librarian query returns the real artifact paths. The current 18-sheet JSON is an **intake ledger only**, not registration.
4. **Game integration:** WS1 adds one optional six-entry row/set to existing 72-actor `inkblobs` catalog (without replacing atlas/UVs/material). Preserve single `mobs2d` actor writer, existing kfbInsert lighting and one gameplay spawn owner. No placeholder sprite if actual bytes missing.
5. **Cartoon deformer:** prefer existing inkblob jump, squash/stretch and wet-ink splash first. Test a bounded animated silhouette deformer only if it adds a new visible soft-bodied behavior (e.g. dragging lobes, asymmetric anticipation, after-bounce wobble) with volume preserved and no swimming eyes/teeth/UV tears. Reuse current code where valid; vehicle deformer is a candidate donor to be isolated, not imported blindly.
6. **Gameplay:** one low-level enemy must spawn/unload, move, be targeted, collide, take a hit, be removed/splatted, leave ink patch and re-load consistently. NPC friendly variants require an explicit state/category; no automatic aggression for an ordinary Normie. Collision, projectiles and damage remain WS1 / Combat Arena owner modules.
7. **Evidence:** source isolation image + in-world screenshot and short clip, test counts and GPU frame cost under controlled load; direct `https://kayfabizarro.pages.dev/…` and Hub linked route **only once actually published and opened**. No acceptance by raw GitHub URL, GitHub Pages, githack or file link. No unapproved merge/Live.

## Webchat / ChatGPT Images / WSA Workbench — pragmatic architecture
- Keep **human Webchat image generation** separate from paid Work integration: Georg generates and visually approves two six-character images using this prompt contract, then exports source PNG/ZIP. Do **not** assume manual Webchat image use is unlimited, literally free, or billable as zero across every plan.
- **WSA/Work only post-processes:** import approved files, hash, tag, crop QA, catalog/librarian registration, candidate atlas packing, game code, tests and reviews. Avoid triggering another paid image-generation provider automatically. This minimizes image-generation spending in Work without claiming that Work itself consumes no usage.
- **Existing Asset Librarian webchat access:** first check the connected read-only Librarian facade `tools/asset_registry/librarian_tools.py` and current GPT Site; expose its existing search/get/handoff through an authorized plugin/connector or approved tool route instead of writing a new catalog/backend. Webchat can then ask “which L0 Black Ink family still lacks an elderly/military/surreal expression?” from structured tags and thumbnails.
- **Account ChatGPT Images library:** programmatic bulk access is **not verified** by this repo/tool audit. Do not invent an endpoint or claim the Librarian can read it. The safe bridge is explicit user export/attachment of approved PNG/ZIP, then persistent intake. If a provider-supported library connector later exists, WS0 may adopt it with permissions/provenance and source-byte verification.
- **Gap analysis:** compute matrix `tier × archetype × expression × silhouette × demographicRead × region/biome` from *registered/accepted* metadata only; show missing slots to Georg, then hand a precise six-slot prompt back to Webchat. Do not auto-accept generated results or hallucinate missing assets.
- **Human authority:** Georg approves visual series; WS0 reviews source/metadata; WS1 proves in-world behavior. No automated catalogue-to-live promotion.
